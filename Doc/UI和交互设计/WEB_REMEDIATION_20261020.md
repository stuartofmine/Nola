## 已修改

- 会话列表取消逐项卡片；输入框默认单行自适应；附件入口收紧；权限与思考强度采用低密度横排；空会话提供明确入口。
- 修正 320px 窄屏网格最小宽度导致的横向溢出，检查器保留独立滚动与内容区边界。
- 执行过程默认折叠，活动推理在正文出现前可见；执行状态归属对应回复。
- 修复模型推理配置解析：当前协议允许 automatic 不声明 efforts/budgets，只有对应控制方式才要求相关字段。未知控制方式和无效字段仍拒绝。
- 会话配置与模型目录独立加载；目录故障不再连带破坏权限、记忆等配置；错误可以重试；初次加载不显示虚假的保存失败。
- 模型连接支持搜索及折叠详情；账户接入、模型参数和 Agent 成员管理按需展开；探测控件补齐七种语言。
- 自动化加载中不提前宣告不可用；后端未声明定时派发能力时禁用定时编辑并解释实际限制。
