# 原文历史端口与 Skill 验证来源整改

对应主任务 H01/H02/S01。先明确本批端口与自审，随后实施；全部实现完成前不运行编译、测试或语法检查。自动化部分见同目录独立说明。

## 原文历史端口

扩展现有 canonical transcript read 服务，不从长期记忆、UI 缓存或 shell 访问数据库。Host 从正在执行的 ToolContext 注入 requester conversation，模型只能选择具体读取范围。当前本地 Store 是单个本地用户的 authority 边界，普通本人会话读取不被一律分类为敏感数据；该请求不授予访问另一个 Store、其他账户或原始审计/隐藏内容的能力。

新增只读 `QueryCanonicalHistory`。查询类型为搜索或原文范围读取；范围类型为当前会话、本地用户历史或显式会话 ID 集。搜索逐有界会话页消费现有 canonical/BM25 读口，返回 conversation/message/part 稳定身份、标题、原文片段与可继续读取的范围。页大小、总命中和单条原文预算均有上界；未搜索完必须返回 continuation，不能将截断伪报为全部无结果。范围读取校验 requester 与目标存在，以及精确 message/part 所有权，继续执行现有可见性/安全投影门禁。

原同会话 UI 读口继续承担其现有用途；Agent 的 `conversation_recall` 统一消费新的带范围端口。搜索和后续读取不需要通过用户自然语言关键词切换工具，也不让模型猜数据库表结构。

## Skill 验证来源

Verifier 声明方法：`model_judgment` 或 `host_check`。验证结果显式携带来源；删除任意非空字符串即可升级为正式检查的旧契约。模型可以提交语义判断，但该结果始终标为模型判断，不伪装为 Host 已执行检查。

Host 检查引用已经被当前 Core 接收的 execution evidence，给出精确 evidence ID、resource URI、version、check kind 与 predicate。Core 校验 Skill owner、证据所属 session/turn、真实 receipt/check 和对应 verdict；没有 receipt、无关成功、跨 owner、未知引用或资源版本已经改变均拒绝。所有 SkillRuntime 命令入口执行同一验证，包括显式完成时的重新核对，不能绕过 materialized tool 分支。

既有适用的语义检查可声明 model_judgment；机械检查声明 host_check。不同检查不互相替代；后续任意成功不会自动恢复不相关的失败。来源链接仅在实际模型证据链丢失时修复，不强制普通回答套用检索/引用流程。

## 静态自审门禁

1. 请求的 owner 由 Host 取得，scope 不允许选择其他 Store；错误身份明确拒绝。
2. canonical 可见性和控制凭据安全投影复用原端口，不能因为跨会话扩大到隐藏审计原文。
3. 搜索会话页与命中截断必须可继续；读取按字节对齐并返回精确 owner。
4. 检查类型来自 Skill 声明及 Host receipt，不从 verifier 描述或错误文案推导。
5. 验证引用必须解析到正式执行来源；当前资源版本变化使旧检查不再满足完成条件。
6. 当前格式缺少必需方法/来源时明确拒绝；不新增旧字段别名、迁移或数据库重建。

本说明是实施前设计与静态自审，不构成任何测试或真实会话验收证据。

## 实施记录与未闭环边界

`QueryCanonicalHistory` 已接入 Domain、Application 只读分类、Store read port、CLI 会话服务及 `conversation_recall`。搜索每页最多检查 16 个会话、选择最多 20 个命中，按会话 ID 顺序分页并复用各会话既有 BM25；这不是全历史统一排名。返回明确的已检索会话、继续游标和命中截断标记。原文读取使用 UTF-8 字节范围，并可用搜索返回的 conversation revision 防止选择后读取到已变更来源。搜索命中位置仍为字符偏移，不能把它直接作为字节读取偏移；深层原文需从有效字节范围继续读取。

Skill 的声明、materialized updates、Core 命令、checkpoint 投影、CLI/macOS 展示和现有测试源码已统一为结构化来源。`host_check` 不接受任意成功工具调用冒充验证；必须匹配真实执行检查的资源、版本、方法、谓词和结果。后续资源版本变化会在完成时再次拒绝。重新验证须显式提供 `replaces_evidence`，精确指向旧来源；新来源必须先独立通过同一 Host 校验，旧 journal 记录保留。`model_judgment` 可以没有工具来源，但始终是模型判断，不声称独立机械检查。

H02 已确认原网页报告只有文本、后续预算裁剪可能切掉来源链接的链路。Web 搜索现向模型提供有界结构化来源（完整 URL、标题、简短片段、遗漏计数），并保留小型 `structured_preview` 给 Core 裁剪层。URL 超预算时整条遗漏而非切断成假链接；缺少原文须用精确 URL 继续读取，不假称一定存在已持久化全文引用。该变更不保证模型最终回答必然正确引用，也不强制普通无检索回答生成链接。
