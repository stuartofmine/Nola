# 客户端封装实施记录

日期：2026-10-15。已进入统一验收；Android JVM 已完成下述验证，其余端及真实设备/服务场景分别验收，不以源码审计代替动态结果。

## 已实施接口

- iOS `ConversationContextStore` 窄端口提供 `prepareContextCompaction`、`commitContextCompaction`、`replaceContextSummary`；runtime 仅翻译 Context command，候选使用来源 witness，entry 保持 ISO8601。
- iOS `Conversation.configurationRevision` 与 canonical `configuration_revision` 分离 transcript revision。生产整包 settings 写入已迁到稀疏 configuration patch；upsert 对已读取配置版本做 CAS，不使用最新版本重放旧快照。模型参数/override 不再从 metadata 写入。
- macOS/Android canonical 配置读取及模型 CAS 改用 configuration revision；配置提交消费 `committed / conflict / not_found` 结果。
- Android DraftRepository 的 pending/load/remove/validate/retire 使用 suspend IO，去掉 Future.get；构造只装配，pending 恢复异步；草稿展示有 loading 状态，加载不覆盖期间输入。
- Android 保存也已改 `suspend conditionalSave`；首屏/new draft owner 旋转有 initializing/error，加载按字段编辑标记合并，期间显式清空不被恢复覆盖；删除取消旧加载，ViewModel 清理仓储控制器作用域。
- Android 发送入口同步捕获原 owner、草稿对象/编辑 revision、该次保存 Deferred 或已加载版本，等待该保存后形成冻结 submission ticket。canonical Admitted/remote admitted 仅按 ticket 条件退休：IO 前后检查对象和编辑 revision，磁盘 CAS 核对冻结版本；期间新输入、附件或同文重编辑保留，不读取最新 owner/revision 重放清理。提交仅清空匹配版本，pending owner 继续可写，显式删除才写墓碑，避免 ACK IO 后排队的新编辑被墓碑拒绝。
- Android selection 提交仅核对 selection generation，原本 local/API 生成不再阻止 B 加载。设备运行记录 owner；B 提交遇设备占用显式返回资源等待，保留草稿，停止仅针对运行 owner。
- macOS Composer 禁发仅依据所选 owner；失联远端恢复按会话停放/恢复，释放进程内执行槽，generation fence 隔离旧回调。活动槽占用时明确 Waiting 资源结果，原草稿保留；Stop 核验所选 owner。
- macOS browserSnapshot 写入已从业务metadata移至设备本地 MacConversationDraftRecord；浏览工具/导航更新保存本地缓存，canonical reload保留本机投影；恢复标记 disconnected，不将缓存当会话存活、授权或工具证据。旧canonical快照仍可读，未删除原数据。
- iOS `SendConversationTurnUseCase` 持有会话准备、创建、稳定 Turn 身份、每会话 Task、执行配置和取消。View 的 generationTasks、processMessage、创建/草稿转移编排已移出，View 保留展示订阅和乐观投影。
- iOS 本地持久 submission ticket 保存原 owner/草稿版本/原文附件/稳定 user identity/配置版本，先落 ticket 后清空输入。Core admission 或 Web admitted 回执条件退休原版本；期间输入保留，未知 ACK 不重发。重建草稿回原 canonical owner，canonical user message 可用于幂等 reconciliation。
- 原iOS并行执行回归已改走新用例；新增ticket重启、ACK未知原owner恢复、幂等提交及期间新输入保留源码回归。Mac增加unknown远端恢复停放/返回原owner/所选B停止不取消A源码回归；设备浏览缓存加入不进canonical/outbox回归。
- 三原生端发送配置/父位置前置条件：iOS/Android Begin descriptor 与 Mac local request 传 `expected_configuration_revision`、`expected_parent_message_id`，在模型/上下文 await 前读取并冻结。Mac CLI 翻译由 root 接续。

## 仍在进行/未完成

- C01：macOS仍有单个物理Host槽，显式资源等待，不冒充已排队；需统一验证A未知/B发送/回A恢复与取消身份。
- C02：Android已落ChatRunRegistry/ChatRunSession真实owner/run生命周期：独立SupervisorJob、事件投影、Core coordinator、权限、remote observer/journal/receipt/task cursor；API/Web可并发，不再被设备槽限制。仅Local申请进程级模型槽，槽等真正Job completion（含native/NonCancellable teardown）才条件释放，删除/取消不提前放行。同owner后继Run新建session，Stop携owner/responseId、权限携requestId；准备期Stop恢复未发送草稿，不伪造已准入Run完成。Main 发出取消不等于 IO/native 已停止：effect select 立即取消精确子任务，在 NonCancellable 内提交 Core interrupt，随后等待真实 teardown；worker 取消也不跳过该提交。工具外部结果不明保留exact recovery，不伪造失败或 cancellation_confirmed。并发/权限/observer/lease/取消与草稿版本回归已通过 JVM；真实设备/服务端到端仍待验收，无持久客户端排队。
- C03：需验证新 submission ticket 的创建后退出、ACK丢失、失败恢复和新草稿退休；不能以进程内Task转交冒充已提交。
- C04：已移交本分支并落地 application-owned ConversationSubmissionController，接管 submit/select订阅/receipt/event/recovery/history/stop；View只订阅快照和触发意图。workspace按owner持有controller，切换/卸载不取消原提交；删除/Host失效取消所属传输。IndexedDB v2保存稳定身份、原草稿版本和请求ticket，准备/发送前持久化，admitted回执按版本条件退休，后续输入保留。仍需统一类型检查及断连/重启/迟到回执动态验收。
- C05：异步加载与 CAS/墓碑保留，已新增期间编辑/清空回归源码；磁盘锁争用及大附件响应待整体动态验收。
- A01–A06：生产旧整包settings接口已删，Mac业务metadata已迁配置CAS；旧测试语义仍需统一审计（尤其nil配置版本与旧metadata业务写假设）。
