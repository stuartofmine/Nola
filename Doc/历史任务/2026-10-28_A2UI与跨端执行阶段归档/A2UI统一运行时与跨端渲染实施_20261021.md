# A2UI 统一运行时与跨端渲染实施

更新：2026-10-23。状态：**接入改造与集中验证进行中，尚未完成验收。** 用户已授权实施；先完成各层接线和改造，最后统一测试。此前[跨端共享业务收敛与验收](跨端共享业务收敛与验收_20261021.md)暂停，缺口保留，不据此宣称完成。

## 1. 已确定的实施决策

| 项目 | Nola 决策 |
|---|---|
| 唯一逻辑权威 | 现有 Rust Core/Application/Store；协议、绑定、函数、Surface 生命周期与动作裁决只实现一次 |
| Web | 用户指定 `ChaliceForAuri/a2ui-svelte`，复用组件和样式，适配其渲染入口接收 Core 已解析投影 |
| 协议 | 四端统一使用 **A2UI v0.9.1**，固定规范快照；不接入 v1.0 或并行版本 |
| Apple | iOS/macOS 共用 SwiftUI 渲染组件与桥接 DTO，平台仅分导航和系统交互 |
| Android | Compose 消费同一投影；AGenUI 仅作为组件参考，不能带入第二套 C++ Runtime |
| 通信 | 沿用 Apple C ABI、Android 现有 JNI/Core 适配、Web Rust Host 的 HTTP/journal；首期不引入 UniFFI 或浏览器 WASM Runtime |
| 内部模型 | 版本无关的类型化 IR；这不表示实现多个外部协议或升级转换器 |
| 状态 | 复用事务、journal、命令回执和恢复；不另建平行事件总线、压缩器或授权系统 |

用户已确定 v0.9.1 为唯一协议基线。Web 库必须适配这一基线，不能反过来推动全端升级。可选择经验证匹配的历史版本，或修改固定源码；选择第三方历史源码不等于保留 Nola 历史协议兼容层。遵守仓库单版本约束：不保留旧协议解析器、字段别名、双读双写或历史迁移；格式不匹配明确拒绝，不能自动改写用户数据。

## 4. Web 库接入细则

上游标准用法不可直接照搬：[`Surface.svelte`](https://github.com/ChaliceForAuri/a2ui-svelte/blob/d0345eeb52c4c84871c82c4f9c0e43f078ac3ffc/src/lib/render/Surface.svelte)接收 `A2uiClient`；[`Node.svelte`](https://github.com/ChaliceForAuri/a2ui-svelte/blob/d0345eeb52c4c84871c82c4f9c0e43f078ac3ffc/src/lib/render/Node.svelte)还执行绑定求值、数据写入和函数请求；[`client.svelte.ts`](https://github.com/ChaliceForAuri/a2ui-svelte/blob/d0345eeb52c4c84871c82c4f9c0e43f078ac3ffc/src/lib/client.svelte.ts)维护独立状态。只伪造一个 client 对象不能消除第二套 Runtime。

v0.9.1 专项适配清单：

- Core 只接受 v0.9.1 的 createSurface/updateComponents/updateDataModel/deleteSurface 和对应 action/error 合同；不接收 v1.0 的双向函数消息、内联初始化等新增 wire 能力。
- 校验 v0.9.1 数据更新的缺省 value 删除与显式 null 值语义，禁止沿用库的 v1.0 null 删除解释。
- 按锁定的 v0.9.1 catalog 逐项核对组件名、属性、插槽、校验、动作与主题。Modal、Tabs、Slider、TextField、选择组件列为重点差异检查对象；实际映射以 schema 为准，不依据旧名猜测。
- Core 将 v0.9.1 解析为内部投影；Web 适配器将该投影接到上游组件 props。这个映射不生成 v1.0 wire 消息，也不保留双协议解析器。v0.9.1 主题经可信设计 token 映射，不接受任意 CSS。
- 用真实 v0.9.1 fixture 验证完整生命周期、数据删除/null、相对绑定、动作与组件属性；v1.0 输入必须拒绝。上游 v1.0 测试通过不能代替此项验收。

实施采用**固定上游源码的受控渲染适配补丁**：保留 basic catalog 组件及视觉资源，改造 Surface/Node/context/Slot 的依赖，使其读取 Core 输出的 resolved props、稳定实例 ID、子节点和验证结果。组件事件只调用 Nola 的 edit/action 端口。不得用类型强转冒充完整 `A2uiClient`；补丁暴露明确的投影组件 API。

生产路径不实例化 `A2uiClient`、不接上游独立 transport、不执行上游 reducer/动态表达式/agent function 请求。P0 沿组件 import graph 检查残留状态写入和函数执行；上游协议工具只允许用于开发夹具对照。保留来源、许可证与补丁说明；升级时重跑差异审计。若组件深耦合，局部改造其输入契约，仍以指定库为组件来源，不悄悄换成另一套 SDK。

### 8.1 远程表单当前约束

- Host 使用现有配对认证、加密传输、来源校验与 Application。查询不领取、不 ACK；新 Run 入场才领取队首并验证身份。
- UI 动作保留同一个 submission_id，用户消息为 `ui:<command>:user`，assistant 为 `<command>:assistant`；冻结请求包含 queued_user_command_id，正文由 Host Core 的持久队列提供。
