## 实测发现并修复

1. 工作区等宽标签在窄屏、大字体时按字断行；改为可水平滚动的自然宽度区段。首次修复的 Compose 无限宽文本布局又被 UI 断言捕获，最终使用明确的 intrinsic width 修正。
2. Android 只恢复等待审批的 Run，普通 Pending/Running 只显示处理中，没有重新接入执行者。当前在恢复检查通过且不存在待决命令/未知外部效果时接回原 Run。
3. HTTP route 手写 JSON 遗漏 `siwc_account:null`，与 Core typed 持久化对象严格比较时误报模型授权失效。现在消费现有 `admit_host_output` 返回的 Core 权威 route，完整保持模型与输出预算校验。
4. 恢复时直接比较带刷新凭据摘要/到期时间的工具 schema，误认为权限发生变化。先复用既有冻结工具校验，再由共享 Core `validate_run_recovery_authority` 比较真正冻结的模型、工具 schema、Host catalog、权限与上下文事实。仅明确的顶层 observation receipt 字段允许续期；不会修改冻结 binding 或替换原任务。
5. 恢复失败被显示成普通 Error，允许新提交，真实重现 `assistant turn cannot overlap an active Run`。现在保持 AwaitingRecovery 并保留草稿，直到原 Run 得到权威结果。
6. 远程后续提交使用本地 configuration revision，无法代表 Host。改为读取共享 Core/Host 的原子 submission frontier，并冻结 revision/parent，校验已显示父消息；尚未完成 Android 远程第二轮真实 UI 验收。
