# 跨端业务复用与真实链路验收

> 2026-10-21 接续说明：当前执行与进度统一移至[新的当前任务](跨端共享业务收敛与验收_20261021.md)。本页保留前序审计与详细范围，不作为另一条并行主线；未完成项由新任务承接。

建立日期：2026-10-20。更新：2026-10-21。状态：**架构收敛实施中；既有局部修复保留，完整端到端验收未完成。**

执行要求：本轮先完成全部改造，再集中并行测试；实现阶段仅编写代码与用例，不提前运行编译、测试或真实模型请求。

本任务作为当前优先主线。目标是让 CLI、Web、iOS、macOS、Android 使用同一套业务决策与协议，消除客户端各自组织压缩、推导权限和维护执行状态造成的行为差异，并补齐真实模型与移动端交互验收。原有 UI、模型、权限任务未完成项继续有效，不因新任务建立而关闭。

## 已确认事实

- Web 自动压缩经 Host 进入 Core；手动 `/compact` 进入 `AgentSubmission::Compact`。Mac 本地聊天通过 `nola-agent-host` 复用同一 CLI Host。不能将其描述成 Web 独立压缩引擎。
- 分叉发生在完整流程：CLI Host 管理分段、续写、预算重写；iOS、Android 分别构造摘要请求，恢复策略不一致。iOS 手动维护虽使用 Core 准备与校验，仍自行组织摘要调用和提交，并存在额外自动触发入口。
- 权限授权和会话配置事务已有 Core 实现，但客户端仍通过多次查询推导权限归属、生效状态，并自行编排模型切换字段。
- Apple Shared 已被两端实际接入，但目前主要覆盖输入组织和文本追加/替换规则，未覆盖完整协议与业务流程。
- 平台布局、键盘、窗口、网络传输、凭据存储及 provider 请求适配不因“复用”而强行合并。
