# CLI 交互与执行边界整改

## 实机证据

会话 `20261009230513438574000-51567-0`：普通 `ls -la` 因缺少
`operation_kind` 被 schema 拒绝；随后一次调用在授权界面返回输入框后取消，
未执行，却显示“命令执行失败”。后续工作区申请有明确 deny 收据，不是授权丢失。
不得以取消或拒绝为理由自动重试、扩大工作区或把 `/allow` 当作系统权限。

## 设计边界

1. Core journal 是执行事实来源。取消、失败、待授权不得合并成一个 error bool 呈现。
2. 工具契约只要求完成调用所必需的参数。shell 的目的声明可选；缺省保守 Execute，
   既不推断只读，也不提供验证证据或豁免权限。
3. 终端 renderer 独占光标、清屏、滚动区域及样式生命周期。正文和工具输出只允许
   安全的行内样式，不允许注入 OSC、光标移动或终端控制。
4. `/allow` 与授权请求使用同一 modal frame 和焦点生命周期。数字只选中，Enter
   确认；Esc/Ctrl+C 退出不提升权限；控制键不能误当成批准快捷键。
5. transcript 保存各次结果，viewport 负责裁剪。高度变化从文档重排，不以删除结果
   换取紧凑；长命令优先保留错误原因。相邻成功读取可合并摘要，失败不能被吞掉。
6. shell 前台结果提供同一 `shell_execution` 对象：command/cwd/state/exit_code/
   stdout/stderr/output_compacted。journal 投影保留结构化结果，UI 不再依赖通用
   “命令失败”摘要猜测原因；退出 0 仍不等于任务已验证完成。
7. 授权补充指令和问答自由输入共用 modal 编辑状态机。4096 字节上限，UTF-8
   安全移动/删除、多行和粘贴、缩放重排、取消恢复父面板；禁止旁路 stdout/read_line。
8. renderer 所有权属于整个 TTY session，不属于某一轮回答。Idle、授权面板、单轮
   完成都不撤销所有权；session guard 退出才排空持久记录并恢复终端模式。
   slash 命令、后台通知、计划卡片与下载进度走同一显示入口。模型选择器也使用
   modal frame，选项视窗有界且始终显示选中项。
9. Markdown 表格在扣除助手缩进后的宽度内排版，避免二次折行破坏边框。
10. 输入事件由单一 broker 读取。实机 PTY 发现缩放与按键相邻到达时，默认
    crossterm Mio 输入源会滞留事件，直到新的输入边沿才释放；线程采样停在
    `kevent`。使用官方 `use-dev-tty` level-triggered 输入源，避免此类等待。
    Unix 零时限探测映射为 1ms readiness probe，因为该后端会跳过零时限轮询；
    不以 sleep 或自动补发按键掩盖问题。

不引入另一套 agent/session 数据源。

## 呈现约定

定位是安静、可追溯的终端工作台。终端字体与背景由用户控制，不强制 RGB 背景；
正文默认色、次要信息弱化、操作强调、错误有文字标记，不以颜色单独表达状态。
紧凑和宽屏均为“历史 → 当前活动 → 输入/临时授权 → 快捷键”；不用空白占位撑高。
按照 apple-design 的 layout/feedback/accessibility 原则检查层级、反馈与键盘访问，
不将 Apple 原生窗口尺寸和控件套用于字符终端。无法从用户截图量出主题对比度，
不宣称达到未经测量的对比度数值。

## 2026-10-10：交互视口与终端滚动历史分离

参考本地 OpenCode `app.tsx` 的单一 renderer 和 session `scrollbox`
管理历史区域的方式，交互模式改为独立屏幕。输入框、进度和 footer 只作为
当前帧绘制，不再由终端主屏滚动缓冲承载；缩放重新投影文档，退出恢复 shell。
非交互输出保持原行为。PageUp / PageDown 在空闲与执行期间均用于翻页历史，
授权面板继续优先处理自身输入。历史布局按文档 revision 和宽度缓存，避免
流式刷新反复排版全部已完成 Markdown。

验证：54 项终端单元测试通过，新增独立屏幕、多次缩放、footer 唯一性与
退出恢复 shell 的回归。3 项真实 PTY 测试通过：中文草稿与高度变化、
流式完成前后、动态缩放及取消后下一条命令。PTY 使用受控响应，不代表
真实模型压缩性能通过；终端原生滚动改为程序内翻页，鼠标选择/滚轮体验
仍需跨终端验证。
