# 跨端对话视觉与动效打磨

状态：第一批五端呈现代码已完成，等待统一回归；未完成全平台视觉验收。

## 设计判断

Nola 的主角是可阅读的答案；执行过程是可追溯的旁注，不是闪烁的仪表盘。
参考本地 `open-claude-ui` 固定版本 `2834bc1` 的 `cds-theme.css`、
`ChatMessageBubbles.tsx`、`ThinkingAccordion.tsx`、`ClaudeMotionPresets.ts`：
采纳单层语义表面、正文阅读列、统一焦点反馈、短促显现；不照搬陶土色、
6px 字符模糊、弹簧超调、无限扩散光圈或生成中禁止折叠。
这是第三方还原项目，不是 Claude 官方规范。

Apple skill 依据：`motion.md › Providing feedback` 要求频繁交互不添加多余运动；
`accessibility.md › Vision/Mobility` 要求语义颜色、足够控件尺寸及可选动效；
`layout.md › Visual hierarchy` 推荐用对齐、缩进和渐进披露表达层级。
Android 保持 Material 控件与 48dp 目标，不模仿 Apple 控件外观。

## Token 与动效方案

- 色彩：延续各端现有 canvas/panel/content/muted/accent/danger 六个语义角色，
  Apple 使用原生动态色，Android 使用 Material ColorScheme，Web 使用现有 CSS
  变量。不硬编码系统色的十六进制近似值；对比度须真实渲染测量，不能虚报。
- 字体：系统正文；次要执行说明采用次级色而非全篇斜体；代码独立等宽字体。
- 间距：4/8/12/16/24；正文与过程之间 14–16；过程内部不重复围框。
- 布局：宽屏 `导航 | 过程 + 正文 + 不透明输入 | 资料`，窄屏 `过程 + 正文 + 输入`。
- 特征：新内容轻柔显现，已读内容静止。每个稳定内容块只显现一次，不重播整卡。
- 动效：交互反馈 120–160ms；新增文字 180–240ms，最大 1px 视觉位移；
  状态点仅 2.4s 周期轻微明暗变化，无尺寸/模糊/阴影扩散。减少动态效果时静止。
- 折叠：用户动作优先；不为每个 token 或状态变更动画化高度。标题保留键盘焦点、
  原生 disclosure 语义，完成状态不冒充任务成功。

自审：去掉扩散光圈这一装饰，而非添加新主题。保留不透明输入、输入下方权限、
三档复杂度；不改模型配置、权限判断、会话数据或 harness。

| 平台 | 实际变更 |
| --- | --- |
| Mac | 状态光移除三层扩散环、发光阴影和缩放；仅局部亮度变化。流式显现由 320ms/5px/1.8px 模糊改为 240ms/1px/0.45px；稳定文字身份与绘制方式不变，320ms 最大视觉积压不变。 |

| Web | 原生 details 语义保留；明确细箭头、短时旋转、hover/focus、静态尺寸状态点；过程内部规则化间距与思考引导线。正文默认约 15.75px，输入至少 16px，代码复制目标桌面 32px/触屏 44px；减少动态效果禁用装饰动效。 |
