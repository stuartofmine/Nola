# Mac UI 交互整改记录（2026-10-09）

## 状态与范围

本轮由用户要求多代理重新审查 Mac UI，随后授权实施。本文记录本轮源码中已落地的修改和待验收项，不将旧一轮测试结果计入本轮，也不以生成截图文件等同于视觉验收通过。

当前状态：实现已整合，Mac Debug 测试构建、整批回归及 Release 构建通过，相关实窗截图已检查。MLX 编译警告不在本轮范围内。

## 一、设计与反思

### 1. 编辑会话不能依赖页面是否挂载

连接草稿、参数基线、冲突状态及恢复说明必须属于同一个编辑会话。原实现保留了 `needsReload`，却把解释原因和提供重新加载入口的 `notice` 放在会随来源切换销毁的视图状态里。单独检查保存逻辑无法发现这一跨页面生命周期问题。

工作区现在为每个窗口持有模型导航、本地模型编辑状态与远程模型草稿，并通过 `MacModelCenterView` 初始化接口注入。页面可卸载，编辑会话不因此丢失；不同工作区窗口也不应共用同一个导航实例。独立模型窗口和设置入口的共享导航不等同于工作区窗口的导航所有权，不在本文中宣称已全部移除。

### 2. 未保存状态应描述差异，而不是描述历史操作

参数编辑曾用单向 `isEdited = true` 表示脏状态，导致改回原值仍弹离页确认。现在使用规范化参数与保存基线的差异，并将非法文本单独纳入待处理状态。对已有模型，恢复基线同时撤销待写入参数；新模型则保留初始参数写入。

### 3. 表单应表达有效配置，而非罗列所有字段

采样能力声明、协议和表单展示不能彼此脱节。本轮不改请求层协议或推理策略，而是让表单读取已有模型能力：不支持采样时禁用采样参数和预设并解释原因；存在“仅关闭思考时支持采样”的声明时显示条件；Responses 模型不再展示仅适用于 Chat 的输出 token 字段选择。

### 4. 错误必须指向可执行的恢复操作

保存属于连接事务，错误却可能来自该连接另一个模型。只在顶部显示“检查参数”不足以完成任务。本轮为参数错误补模型身份及跳转入口，并在高级字段出错时切到高级参数区。运行模型阻止另一个模型启动时，目标模型页也应提供停止当前运行模型的操作，而非仅留下禁用按钮。

### 5. 本轮审查纠错

初审曾根据菜单视图只使用 `displayName`，判断同名 API 模型无法区分。继续追踪 `MacChatModelCatalog.load` 后确认：其展示名称原本已包含模型名和连接名。因此撤回该缺陷判断，不能把它计作本轮修复成果。本轮默认菜单的实际新增内容仅为当前显式默认项的勾选标记。

测试证据同样需要校正：名称叫“modelCenter”的旧截图测试未必承载完整 `MacModelCenterView`；断言 PNG 有内容只能证明成功输出文件，不能证明头部层级、错误可恢复性或窄窗口可用性合格。

## 二、已实施内容

### 模型中心与参数

- `MacRemoteModelEditingState` 持有冲突通知；重新加载状态即使没有通知对象，也会显示相应反馈及恢复入口。
- `MacModelParameterDraft` 保存初始参数基线，通过值差异和非法输入计算脏状态；统一 `updateParameterDraft` 处理待写入集合。
- 参数错误显示模型名，反馈详情可前往出错模型，并按非法字段选择常用或高级页。
- 默认模型菜单为当前显式默认项显示勾选。
- 远程模型常用/高级参数以及会话模型参数读取采样能力；不适用控件禁用并提供说明。条件采样显示限制提示。
- Responses 详情不再显示 Chat 专用输出 token 字段选择。
- 参数表单改用共享 `Grid` 列，对齐标签和输入框；详情头部移除重复的用途徽标、优先级摘要和保存说明，保留模型身份与主要操作。
- 查看非运行模型时，展示当前运行模型并允许停止它。
- 模型库补上下方向键移动、连接级 Command-S 保存；键盘与辅助功能实际行为仍需统一验收。
- `MacModelCenterView` 支持注入远程/本地编辑 owner，工作区已有对应窗口级 owner 接线。

主要文件：`NolaMac/UI/MacModelCenterView.swift`、`MacRemoteModelManagerView.swift`、`MacModelParametersView.swift`、`MacLocalModelManagerView.swift`、`NolaMac/Features/Chat/MacConversationModelSettingsView.swift`、`NolaMac/UI/MacChatWorkspaceView.swift`。

### 侧栏及权限语义

已核对源码：会话列表区分“暂无会话”和“无搜索结果”；后者提供清除搜索，前者提供创建会话操作。能力中心将未授权项描述为可按需申请，而非将默认未授权等同于整体故障；权限变化不重排行序，避免正在操作的行跳动。

这部分其他实现细节及统一测试结果由工作区负责代理和主代理补充，不在本文中推断未检查的行为。

### 本地化

本轮新增 9 个键，沿用现有 catalog 格式，覆盖当前 9 个语言：英语、简体中文、繁体中文、日语、韩语、法语、德语、西班牙语、俄语。

- `ModelCenter.xcstrings`：`Review parameters`、`Sampling controls are unavailable for this model.`、`Stop running model`。
- `Localizable.xcstrings`：`No conversations yet`、`No matching conversations`、`Clear Search`、`mac.capabilities.access_available`、`mac.capabilities.available_on_request`、`mac.capabilities.not_authorized`。
- 按需权限数量保留 `%d` 占位符。既有语义相似但 key 不同的文案不视为相同条目，不覆盖旧翻译。

## 三、新增回归与验收要求

`MacModelCenterEditingTests` 新增：

1. 参数从非法值恢复基线后重回干净状态，布尔参数往返也如此。
2. 冲突通知由编辑会话保留。
3. 已有模型恢复原参数后移除 pending write，跨连接导航不再误弹确认。
4. 新模型即使未修改参数仍保留初始参数写入。

验收覆盖要求（实际结果见第五节，未覆盖项不得据此宣称完成）：

- 整批 Mac 编译和相关测试；不得复用上一轮结果冒充本轮通过。
- 实际完整模型中心在中英文、窄/宽窗口、长名称和错误态下的人工截图检查；检查共享列、头部高度和控件是否可达。
- 冲突后切换模型来源及工作区模块再返回，保留原因、草稿与恢复操作。
- 同连接跨模型错误跳转、Command-S、方向键、禁用原因和本地运行模型停止路径。
- 辅助功能实际选中语义和焦点行为；源码有键盘处理不等于已完成 VoiceOver 验证。

## 四、聊天 Markdown 标准 AST 与展示整改

- Mac 目标固定引入 `swift-markdown 0.9.0`，使用 CommonMark/GFM AST 负责块结构，原生 SwiftUI 负责排版和渐显。列表项及引用递归持有子块，不再在遇到空行或代码围栏时被顶层切分器拆散。
- 行内内容从 AST 的 UTF-8 源码范围取得，保留数学表达式、强调及 Unicode 源文；HTML 作为非执行文本处理。已有脚注展示扩展保留。
- 引用式链接携带标准解析器已解析的目标地址进入行内渲染；脚注扩展不改写 AST 判定的代码区域。每次视图求值复用同一块快照，避免逐块重复解析整篇文档。
- 日志消息的实时与完成展示使用同一文档视图，保留有界文本读取、追加渐显及已展示内容的挂载状态；语义流组装器也保留列表与引用容器的连续性。
- 统一标题字号层级、提高行内代码及表格字号。普通复制导出可读纯文本，“复制 Markdown”保留原文。
- 新增多段列表、嵌套引用、围栏代码、Unicode/数学源码、五种分块尺寸的流式终态一致性回归。实际通过情况以第五节为准。
- 流式文档复用语义组装器的表头确认状态，未完整到达的表格分隔行不会闪出原始控制语法；完成时普通竖线文本不会丢失。

### 聊天输入、权限与工作区补充

- 权限和追问面板放入有限高滚动区域，输入框位于区域之外；默认展示真实工具参数，不截断选项说明。
- 原生输入委托同步写回草稿，避免 Return 提交旧值；保留输入法标记文本。听写追加到已有草稿并保护后续手动编辑，异步回调由代次隔离，错误可见。
- 思考标题使用可操作按钮，流式期间也允许手动收起并保留用户选择。
- 三栏布局将侧栏实际宽度及分隔线纳入预算，空间不足时切换覆盖式检查器；检查器页签及模块选择由窗口持有。
- 自动化保存错误在编辑弹窗内展示，新草稿 ID 在重试间保持稳定；候选列表先持久化成功，再发布内存状态，避免失败后出现幽灵条目或重复插入。
- 边界：听写追加到草稿末尾，不是任意光标位置插入；页面卸载后保留页签但不保留像素滚动位置；跨段选择沿用独立选择文本窗口，不宣称已改为原生跨段拖选。
