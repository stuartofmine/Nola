## 已确定的产品方向

### A. UI 与多 Agent 会话

覆盖 macOS、iOS、Android、Web 和 CLI；共享交互语义，遵守各平台自身控件和输入习惯。

1. 视觉方向为 **水墨青山**：纸白、墨灰、低饱和山青的语义体系，不再以亮蓝为品牌主色。不用山水背景或装饰纹理影响阅读。具体色值、浅深色、对比度、间距、字体、圆角及动效参数由设计阶段定稿。
2. IM/Telegram 风格组织多 Agent；每个 Agent、每个会话独立维护配置、草稿、数据和执行状态。切换会话不得继承别处的忙碌或错误状态。
3. 不指定收件人，由主控根据能力和上下文选择适合的 Agent；不得用自然语言关键词规则代替模型决策。
4. 指定收件人使用 `@` 提及和候选选择，不额外要求用户操作复杂的收件人配置。显示实际收件人和可恢复的分派失败。
5. 收到消息即显示处理中；区分本地发送中、已接受、分派中、执行中、等待授权、完成、失败与取消，不在尚未接受时伪称执行成功。
6. Agent 内部工具调用默认折叠，常规视图呈现简洁过程摘要。思考、工具、正文保留真实事件顺序及稳定分组；需要用户决策的授权和错误不能隐藏在折叠内部。
7. 统一消息组件、工具组件、间距、状态反馈与低干扰动效；解决流式闪烁、滚动跳动、完成后空白、CLI footer 残影。尊重减少动态效果、键盘导航和读屏。

设计入口：[UI 总览](../../UI和交互设计/README.md)、[设计系统](../../UI和交互设计/DESIGN_SYSTEM.md)。设计系统已改为水墨青山语义色；代码接线不代表已完成全端视觉审查或可访问性验收。

### B. Nola 模型、账户与网关接入

参考 Magpie 的来源专用适配及生命周期管理，不仅增加一个 URL/API Key 表单。明确区分：

- 导入其他客户端已有模型连接配置。
- 复用已有登录或新增订阅登录，按账户管理凭据和刷新。
- 让外部客户端连接 Nola 网关（与导入方向相反，单独设计与验证）。

优先核对 OpenCode、Codex、Kimi 的真实路径和能力边界；不能承诺所有认证均可导入。Kimi Code CLI、桌面 Work Agent 和 Work 订阅分别建模。非公开接口须明确支持范围和失效处理，不能静默切换账户、服务或计费档位。

## 模块契约与责任

以下为待设计接口职责，不是现有类型名或已实现接口。

| 模块 | 输入 → 输出 | 所有权与约束 |
|---|---|---|
| 导入服务 | 来源引用 → 候选计划；用户选择 → 逐项执行结果 | 只读来源；检测重复、名称冲突、自身网关循环；确认时复核；不让 UI 往返传递秘密 |
| 连接与账户仓库 | 明确配置命令 → 稳定 ID、版本化快照 | 身份、显示名、地址与凭据引用分离；独立保存，其他端点错误不阻塞；无隐式删除 |
| 来源/认证适配器 | 授权操作、账户引用 → 登录状态、凭据句柄 | 声明支持发现/导入/登录/刷新/断开哪些操作；区分拒绝、取消、过期与暂时故障；不擅自读取或修改其他应用秘密 |
| 模型目录 | 连接和账户引用 → 带来源与时间的模型能力目录 | 服务商目录和用户启用选择分离；刷新不覆盖用户取消选择；保留上下文、模态、推理档位 |
| 能力探测 | 连接、模型、协议、草稿版本 → 结构化证据 | 未知不等于不支持；声明、探测和用户覆盖分离；限并发、可取消；不隐式产生付费探测 |
| 路由与协议传输 | 会话配置快照、模型请求 → 流事件及尝试记录 | 同协议优先保真；会话账户亲和性；已提交内容后的错误不得静默切换拼接；工具权限仍归 Core |
| 用量账本 | attempt 标识及 usage 事件 → 调用账目、会话累计值 | 缺失不当零、局部不覆盖全部、幂等归并；统计与缓存亲和性分离；持久化跟随会话 |
| 客户端适配器 | 用户确认的连接方案 → 外部客户端配置及连接状态 | 只修改明确拥有的字段；保留用户配置；断开和失败回滚有边界；不与供应商适配器混用 |
| 会话呈现 | 会话/Agent 标识及有序事件 → 稳定 UI 投影 | 展示层不决定授权或路由；取消订阅和迟到回调按 owner 隔离 |

## 必须覆盖的验收

- 导入重复、地址变化、确认前来源变化、部分成功、凭据拒绝；未知供应商不能猜测密钥目标。
- 同连接多协议、模型能力不同、无模型列表但手动模型可调用；目录刷新不重新启用用户禁用项。
- 账户切换、令牌刷新并发、取消、429/5xx 与 401 区分；秘密不进入日志、截图和诊断正文。
- 流式首内容前/后失败、工具参数流、完整结束标记；不重复执行有副作用请求。
- 缓存首次写入但读取为零、TTL、重启、usage 局部更新；会话累计统计正确且不串会话。
- 不指定收件人、@收件人、分派失败、授权等待、切换会话、恢复及多 Agent 并发。
- 各端浅深色、窄窗、大字体、键盘/读屏、减少动态效果；真实流式滚动及 CLI 输入区残影。
