# 跨平台 UI 流畅性审查（2026-11-10）

目标：让阅读、输入和导航保持稳定，新增回复像从水面浮现，控件状态变化简洁可辨。
本轮审查涵盖源码、真实原生测试窗口、模拟器页面及生产构建浏览器回放；未连接到
用户正在使用的 Mac 应用窗口，不将代码检查称作每个按钮都已实机验收。

## 发现与处理

| 范围 | 具体问题 | 本轮处理 |
| --- | --- | --- |
| Apple 普通内容表面 | 填充之外普遍叠加渐变、高光和投影，阅读层级繁杂 | 保留语义填充及一层边框，覆盖层按需显式使用投影；保留增强对比度 |
| Android 普通表面 | 默认渐变、高光和阴影重复强化容器 | 实色填充、轻边框，普通内容默认不抬高 |
| Web 卡片及按钮 | 内外阴影和渐变重复；全局按下缩放使细字和目标位置变化 | 主题色平面样式，按下保留颜色反馈；真实指针测试验证几何不变 |
| Apple 流式绘制 | 大块增量可让活跃字形绘制量过大 | 仅最后 384 字符进入活跃窗口，run 内最多三 glyph 合并绘制；全文立即可读 |
| iOS 跟随 | 48ms 步进产生明显的阶梯感 | 原有合并窗口改成 12 次 16ms；不延长追尾窗口 |
| Android 跟随 | 高频 delta 重启带延迟的 effect，持续输出可能等到停顿才跟随 | 单个逐帧消费者与合并请求通道；实际布局高度变化也唤醒，不只监听文字长度 |
| Android 阅读所有权 | 手势与布局状态合并可能漏掉接管时机；惯性末帧提前清除所有权 | 直接消费拖动开始，原生嵌套滚动处理已消费位移与最终视口，再释放所有权；阅读历史不追尾，提供返回最新按钮 |
| Android 主导航 | 依赖框架默认切换时序，各页反馈不明确 | 显式短淡入淡出，减少动态效果时立即切换 |
| Web 异步导航 | 懒加载页未就绪就给加载容器焦点，实际页面出现后焦点不连贯 | 挂载后按导航代数移交焦点；过期页面、模态、已有输入焦点优先处理 |
| Web 手机入口 | 直接打开裸 chat 与点击对话入口落在不同页面 | 都进入会话列表，显式会话及 Host 链接语义保留 |
| Web 审查空态 | 没选择会话被表现成读取失败 | 选择会话的空态和入口；无目标时禁用刷新，真实错误仍可重试 |
| Windows 启动 | 窗口底色不匹配深色；装饰层重，长详情挤走恢复按钮 | 系统主题底色与监听，单层中性卡片；详情可键盘滚动且限制高度，操作保持可见 |
| 原生页面截图 | 可访问性节点出现早于 push 转场完成 | 保留动画并等待完成后截图，不通过全局禁用动画掩盖问题 |

水面波形仍是 520ms、3 单位位移、0.65 单位柔焦与低透明度渐清；完成尾部
最多 160ms。减少动态效果、修订及历史立即显示。没有把水面效果改成纯淡入。

## 验证与边界

- macOS：完整 Test 配置测试 1,220 通过、2 项显式选择型测试跳过，零失败；
  覆盖真实次级页面、设置分类、回复开合、绘制像素及新增大块增量预算。
  页面循环不再关闭全部动画，复核 104 张次级页面画面及 44 张检查器画面。
  另行完成正常签名 Debug 构建及签名验证。
- iOS：iPhone 模拟器组件、流式与实际应用导航共 32 项通过；浅深色覆盖
  四个主入口、模型、专家、技能、通知、更新、隐私、记忆、计划和信息来源。
  重新运行实际导航，复核 32 张转场稳定后的截图；组件另覆盖 320/834pt
  与最大辅助字号，不等同于物理 iPad 全流程验收。
- Web：生产构建下 184 个页面/区域布局，320/390/1440 三种宽度及浅深色，
  启用实际动画；检查横向溢出、导航、空态、按下几何和延迟加载焦点。
  开合、键盘焦点及水面输出的独立回放通过。类型检查零错误/警告，613 项单测通过。
- Windows：TypeScript 构建、7 项单测，以及真实启动 HTML 的 8 个主题/宽度/状态
  组合通过，包括长错误、键盘滚动、转义和减少动态效果。当前机器不是 Windows，
  原生窗口边框、Segoe UI 和系统主题事件仍需 Windows 环境实测。
- CLI：隔离 PTY 的 10 项 Goal/引导/取消/终端恢复检查通过；终端使用自身帧合并，
  本轮未给终端增加 GUI 动画。

Android：构建和 692 项 JVM 测试完成，其中 2 项显式选择型测试跳过，零失败。
真实设备端的手机页面矩阵、回复开合、原生连续跟随和水面绘制均通过；原生连续
跟随与水面最终一组 3 项通过。紧凑侧栏、展开侧栏两组真实 MainActivity 页面
测试也通过，手机 28 张、两种侧栏各 32 张截图，共 92 张浅深色页面画面。侧栏
通过隔离模拟器调整密度触发布局，验证响应式分支，不代表物理平板体验验收。

此前仅更新 messages 的测试夹具被活动回复 currentResponse 投影替换，未产生
实际长正文；已纠正，增加真实溢出、手势暂停、返回最新及恢复后布局高度变化
断言。不能把旧夹具的成功算作连续跟随证据。原生滚动恢复缺陷曾在加强后的
测试中稳定失败，使用实际已消费位移和最终 fling 回调修复后通过。

浏览器 API 使用隔离夹具，服务不可用画面用于错误/重试状态检查；本轮不进行计费
推理，不修改用户账户、系统授权、真实会话或数据库。未进行物理设备全量帧率测量，
不以布局检查或单测数量宣称所有设备达到固定帧率。未知格式/版本边界及 1.0.0
兼容基线未改动。
