# 跨平台交互检查与修复（2026-11-10）

## 交互约定

依据本机 apple-design 的 Entering data、Onboarding、Managing accounts、Feedback、Accessibility、Focus and selection 参考：先说明操作结果，再要求输入；一个阶段有一个主要动作；异步操作明确等待、成功、失败和可恢复入口；保留用户草稿；取消不伪报撤销成功；键盘焦点跟随任务并返回发起位置。颜色使用主题语义色，窄屏允许换行，减少动态效果时不强行动画。

同时对照本机 `参考资料/codex-main/codex-rs/tui/src/chatwidget/goal_menu.rs` 的独立目标编辑输入及暂停恢复选择，以及 `codex-rs/login/src/server.rs` 在建立授权流程后打开浏览器的处理。采用明确输入目的、保留原文和浏览器自动引导；Nola 的目标状态、授权回执和账户保存仍由自身协议处理。

## 已调整的流程

- CLI：裸 `/goal` 进入专用目标输入状态，直接输入目标原文，展示示例及提交/取消说明；不把目标文本再次当 slash 命令解释，不混入普通聊天历史。Esc 返回聊天。高级直接命令继续使用原解析器。取消、等待用户、恢复的说明与状态保持一致，不宣称有用户未设置的约束。
- macOS：ChatGPT 登录由一次明确点击开始，自动打开已校验的授权网页，授权后自动保存。失败可重新打开网页或检查账户；未知结果不自动重复保存。保存后“选择模型”才读取目录并进入对应连接；不自动启用模型、不发送推理请求。取消和关闭使迟到结果失效。账户过期直接显示重新登录入口，已退出账户不显示可执行的退出操作。
- 各平台目标面板：解释目标用途和示例，约束作为可选补充，当前会话未建立时明确指引；停止前说明会停止自动执行、保留会话与结果。停止命令绑定用户看到的目标和控制令牌，切换会话不沿用旧确认。
- iOS 压缩：补齐只读规划命令分类，预算拒绝不再显示成待确认写入或阻塞保存；保留原会话并提供本地化的模型选择指引。
- iOS 健康状态：HealthKit 明确报告尚未请求授权时显示等待授权，不再作为红色英文读取失败；授权被拒和真正读取失败继续保留错误反馈。
- iOS：首页内容入口与刷新、预设选择与预览分别使用独立按钮，消除父手势和子按钮竞争。下载控制补齐触控面积和无障碍名称，删除失败显示错误而非静默忽略。通知操作和说明卡片使用主题色，清除遗留的固定蓝色。
- Android：目标动作窄屏换行，提交期间禁用输入和重复操作；查询待处理回执失败也会解除忙碌状态；未知结果保留待处理信息。状态名称本地化，未知状态不解释为成功。活动搜索标签保持单行，避免长文本挤高输入栏。
- Web：弹出面板打开时移入焦点，关闭时按实际焦点归还；改变窗口尺寸关闭旧定位。设置页按路由挂载 Windows 启动设置，初次读取失败可重试，写入结果丢失先查询实际状态，不盲目重放。
- macOS 次级页面：代码复制失败有错误反馈，流式代码更新后撤销旧的复制状态；连续复制/保存使用最新操作的提示周期，旧计时器不能清掉新提示；连接设置的主要按钮也使用主题色。
- Apple 模型目录：用有界数据块替代逐字节异步迭代，保留 2 MB 响应上限、重定向拒绝、取消及并发读取限制；防止目录载入长时间无法结束。
- macOS 模型与权限：模型可用性先查缓存再解析已安装目录；远端权限保存失败时保留已确认的源策略，不把未保存的更改展示成已生效。iOS 显式发布云端聊天配置时记录 `chat` 声明，保留已有能力集合，不推断工具、视觉和推理能力。
- macOS 房间：启动和恢复先认领当前冻结的执行意图，再按本地或远端执行源恢复；远端任务不再误查本地 Run，已有本地执行也不会跳过恢复与取消协调。
- Windows：启动/错误页统一主题色、按钮留白、悬停和键盘状态；支持减少动态效果与高对比。重启 Host 防重复提交，失败能恢复操作。

## 摘要计算的用途

内部元数据缓存使用结构化字段和 `HashMap` 自带的键比较，取消“序列化后再 SHA-256”的外层摘要；终端统计相同历史内容的出现次数直接比较原文，不逐条计算摘要。执行恢复在一个读取快照中传递已校验的配置，恢复规划在一个事务内共用同一份检查点，去掉重复读取、摘要计算、解码和回放。

保留发布签名、外部协议要求、凭据指纹、持久化内容身份及独立读取边界的完整性验证。现有字段声明为 SHA-256 的格式不静默更换算法；ARM 构建启用运行时检测的 SHA 指令并保留无硬件支持时的软件实现，开发和测试构建也优化其计算内核。没有新增摘要算法或持久化缓存格式。
