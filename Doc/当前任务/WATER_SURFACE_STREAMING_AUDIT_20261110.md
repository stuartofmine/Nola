# 水面浮现与可读性检查（2026-11-10）

## 实现

按照用户要求保留水面浮现：新文字从基线下方轻轻上浮，柔焦和透明度沿正文方向收清。
这是 Nola 的绘制参数，不是对 ChatGPT 私有实现或精确时间参数的声明。

- Apple、Android、Web 使用同一 520ms 波形，完成后最多 160ms 收尾，位移 3 单位、blur 0.65、初始 opacity 0.08。Android 换算显示密度；Web 使用保留正常换行的 inline 相对位移。
- 已显示前缀保持位置和原起始时间；批次顺序明确，后批波头不超越前批尾部。Apple 不再按日期排序字典，避免相同时间戳产生不稳定顺序。
- Android/Web 分组遵守 grapheme 边界，跨批次延伸的组合字符直接完整显示。突发内容超出活跃片段上限时前缀立即清晰，不产生待输出队列。
- Web 在流式结束后保留原组件完成收尾，并保留用户选区。恢复历史直接使用静态正文，完成收尾后解除系统动画偏好监听。Reduced Motion 立即移除装饰效果，切回时不重播历史。
- Android 将流式状态与是否允许装饰动画分开传递，完成状态不再强制清掉尾部动画。原生 TextView 在追加和完成时保持身份及完整正文。
- Mac 检查器正文、详情与注释采用 13/12/11pt 角色；详情展开不再缩放字形。

不改动协议、数据库、模型正文、完成回执或账户凭据。
