# 规范会话备份中的 Part 来源

Mac 备份会保留规范 Message/Part 的原始字段、独立时间和 content_digest。
分支产生的 Part 若有来源记录，备份在该 Part 上增加可选 `derivation` 对象，
记录目标、直接来源、已知根来源以及两个原文字段的长度和 SHA-256。
旧备份没有这个字段时仍可恢复；缺少来源记录不等于可以推断历史身份。

备份导出分开读取消息元数据、原文字节范围和单个来源记录，并固定会话 revision。
若导出期间会话改变，或元数据声明有来源但来源读取失败，导出会失败，避免生成不完整备份。
Mac 恢复会先准备条目，最终一次提交会话、原文绑定与来源记录。

来源声明不等于执行权限。导入端会将来源标记为 `archive`；即使文件来自本机，
也不能通过备份自行声明 `local_branch`。删除最初的源会话不会删除备份中的来源声明。
历史工具的参数、权限或 owner 仍须通过当前运行协议验证。

Web 的 JSON 会话导出包含：

- `conversation`、`messages`：现有 Web 展示数据。
- `canonical`：规范会话及原始 Message/Part，包含可选的纯 `derivation` 声明。

`canonical` 保存原始结构，展示消息可能是转换后的内容。Markdown 导出仍是便于阅读的文本，
不是完整规范备份。Web JSON 导出目前会在客户端整体构建输出；逐条 Service 查询有界，
但整个导出文件的内存占用尚未完成流式改造。
