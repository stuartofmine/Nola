# 移动执行、模型位置与数据边界

状态：目标设计，2026-10-15；桥接见[共享接入](MOBILE_SHARED_CORE.md)。

## 三个独立维度

| 维度 | 可选位置 | 含义 |
|---|---|---|
| 决策/Application authority | 本机嵌入或已认证远端 | 谁提交该 Run 的状态与决定 |
| 模型推理 | 本机模型或外部模型服务 | prompt、工具结果、附件是否发给模型服务 |
| 工具执行 | 设备、桌面 Host 或获准 bridge | 谁解析资源并执行实际副作用 |

本机 Core 调外部 API 仍会外发模型输入；远端 Core 使用本机模型也会收到客户端发送的输入。
用户提示、附件、召回内容、设备工具结果都须按实际目的地计入数据路径，不能承诺远端模式“只有提示和附件”。
对外发限制的政策校验位于实际请求编译/发送边界；已有目录授权不能自动授予所有接收方读取结果的权限。
本设计定义边界，不宣称已有完整正文敏感信息识别或外发确认能力；缺口须显式跟踪。

## 工具与授权

工具声明包含稳定 ID、schema、目标、可用性与取消/恢复语义；模型不能在参数中换执行目标。
Core 根据具体资源求应用授权；平台 Host 解析资源和当前 OS 授权事实。
资源解析可能先于授权，但未经准入不能发生目标副作用；不为模型任意路径主动弹系统 picker。
应用 Allow 可以来自有效策略，无需每次再点击；OS 授权缺失时才呈现平台所需流程。
执行前复核具体资源与撤销，结果返回原 Run/effect，不从当前选中页面取 owner。
能力未实现、权限拒绝、平台不支持、数据外发受限为不同结果。

## 连接与恢复

paired Host 的稳定身份、认证和可选证书 pin 独立于地址；改变地址不能悄悄继承另一 authority 的状态。
断线保存原 Run 与未知效果，先核对回执；不将断线统一解释为取消或允许切换设备继续执行。
忘记配对撤销当前连接能力，保留历史记录；在途操作标明状态与核对要求，不声称远端效果已消失。
移动进程和前后台受 OS 生命周期约束，持久化仅保证可恢复边界，不保证常驻执行。

## 安全传输与决定

协议与实现从统一 transport/安全端口读取，具体版本和密码学参数以对应实现及安全专项审查为准。
模型凭据与配对秘密仅安全引用，普通配置/草稿/日志不保存明文。
授权回答先验证认证、scope、原请求、参数/来源、有效期与开放状态，再原子消费决定并提交回执。
无效回答不能消耗真实等待；同回答幂等，异回答冲突。nonce 自洽不等于来源可信。
单版本迁移删除旧 Bearer/字段别名等旁路，不把历史实现描述作为继续保留它们的设计理由。

## 验收

### Android Room 当前所有权实现（2026-10-19）

Room 是成员 Context 的聚合投影，不是共享推理 Session。`AgentRoomRepository` 读取规范 room/participant 映射；每个成员通过自己的 conversation ID 绑定 `ChatRunRegistry` session、模型配置、草稿、权限等待和 Run。创建 Agent 显式选择模型并捕获对应参数，不修改其他成员配置。普通历史过滤规范 `agentRoomOwner`，后台恢复仍使用全量 Context。

发送收件人与检查中的成员分开保存；退出成员仍可查看原 Run、回答原权限请求或停止原 Run，但不能因此恢复为新发送目标。后台加载在 owner session scope 执行，不借用当前页面选择；加载 generation 拒绝过时页面结果，逐成员错误不会中断其他成员历史恢复。Admitted 仅 CAS 清理原 Context 的提交草稿，可观察状态立即刷新输入框，新编辑不被清除。

持久命令 journal 按已知 command schema 提取规范 conversation owner；run-only 命令经 `load_run_identity` 解析。远端 admission/journal/context usage/terminal consumer 同样使用各自精确 identity 字段，不按任意嵌套字段猜测。相同 owner 和全局命令互锁，不同 Context 可独立提交；回执按 request ID 精确退休。无效恢复回执保留原 pending，仅阻断其 owner，不让整个 runtime 初始化失败。这是本版本的不确定提交恢复，不是格式兼容转换。

真实 Android 本机 Core→外部模型已验证双成员重叠运行与原 A pending 下 B 独立完成；证据见[历史实施记录](../../../历史任务/2026-10-19_当前任务归档/MULTI_AGENT_IMPLEMENTATION.md)。这不涵盖 CLI warm checkpoint 到 Android 的跨客户端执行配置同步，也不等同于 WebHost 真实并行或真实工具副作用权限验收；不匹配 checkpoint 明确拒绝，不自动改写用户数据。
