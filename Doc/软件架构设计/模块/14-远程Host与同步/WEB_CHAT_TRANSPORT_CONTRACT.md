# Web / Native Host 传输契约

状态：当前单版本的目标约束，2026-10-15。端点实现以 cli/src/web_parts 的路由与协议类型为准；
本文不把旧审计列出的字段别名、Trace barrier 或 DOM helper 定为必须兼容的接口。

## 用例与身份

创建、配置、发送、取消、决定等待、检查状态与恢复分别对应 Application 用例。
浏览器持久保存发送身份再派发；submission_id 与 Application request_id 的对应关系由 adapter 一次绑定，
不能在重连时生成新身份。会话/Run/消息身份来自准入绑定，不能推导或忽略大小写。
配置更新使用共享类型化 patch，不通过 profile 顺带改业务设置。

## 流与投影

SSE 字节块不等于事件边界，处理分片 UTF-8、多行 data、心跳和结构化 HTTP 错误。
正式增量必须有已提交来源、owner、epoch、前置/新水位和稳定 Part identity；
传输进度可以作为临时 overlay，Trace 只作诊断。
客户端按源范围判断缺口，不假设过滤后的诊断 sequence 连续；正式流有缺口时补读或重新获取同范围快照。

流式/结束更新已有 Part，不另构造最终正文。EOF、[DONE]、HTTP 200 与 terminal Trace 不表示业务封存。
终态提示触发按原 Run 读取 canonical seal/回执；迟到费用允许在原 Attempt 的独立水位推进。
投影通知可仅携带身份/游标，也可携带有界提交 patch；不得强制每个 token 全量重载整份历史。

## 等待、取消与恢复

授权回答携带原 wait/request、Run、Host/source 和决定身份；Application 原子校验与接受。
HTTP 送达确认不替代持久决定，关闭面板或网络断开不等于 Deny。
失败按原决定身份核对和重试，不重新申请或扩大资源范围。

取消绑定精确 Run 和稳定 cancellation/request identity；取消传输不等于取消执行。
取消已接收、执行停止、效果未知分别返回。以某会话一个字段发“取消当前任意 Run”不满足目标契约。
恢复读取原 Run 与冻结调用，不允许附带新用户消息或任意模型覆盖。
封存 Run 的继续任务另建关联 Run；未封存恢复不能重发用户输入。

切换/卸载页面可终止窗口流订阅；已提交工作、回执核对和完成观察由独立 controller 管理。
有资源限制时显示正式 WaitingResource，另一会话恢复异常不能成为工作区永久禁发状态。

协议测试覆盖拆包、重复、乱序、来源更换、回执丢失、晚终态、晚 usage、授权幂等和取消竞争。
UI 测试验证切换、滚动、正文/过程稳定 identity 及历史分页；真实模型验收另行提供。
