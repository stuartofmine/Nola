# 历史问题到架构验收的映射

状态：验收要求，不是测试通过记录。2026-10-15。

## 问题不能只按截图修复

| 已讨论问题 | 主要责任边界 | 必须验证的不变量 |
|---|---|---|
| A 执行时 B 输入框显示执行中 | 客户端投影、Run 生命周期 | A/B 输入和等待状态独立；旧回调只更新 A |
| 新端点被其他端点错误阻止保存 | 模型目录用例 | 编辑对象隔离校验；引用完整性错误只阻止受影响提交 |
| 参数、模型、权限恢复错误 | 会话配置、草稿、目录 | 已有会话配置不被全局或草稿覆盖；冲突保留用户编辑 |
| /allow 后仍反复询问 | 应用授权、平台权限、等待协议 | 同一决定幂等；应用自动批准与 OS 拒绝分别呈现 |
| 任务断开后永久卡住 | Supervisor、回执与恢复 | 查询不重执行；结果未知不冒充失败；其他会话可用 |
| 首 token 慢、思考不流式 | 启动、上下文、模型适配、投影 | 分段测量定位；思考/正文类型与完成状态正确 |
| 压缩失败、过慢、丢 Goal 约束 | Context、物理快照、任务存储 | 原文不变、候选原子提交、任务权威独立恢复 |
| 缓存率总为零或切换丢失 | Attempt 账本、provider usage | unknown 与 0 分开，按会话加权持久统计且去重 |
| 工具名原样输出、思考/工具错位 | 协议投影与展示映射 | ID 稳定、标题本地化、保留因果顺序，不从文案推断状态 |
| 页面闪烁、结束空白、底部卡顿 | 稳定 Part、组件订阅、滚动状态 | seal 不重建消息；用户离开底部不被强制拉回 |
| CLI 输入栏/footer 残影 | 终端布局所有者 | 唯一 renderer，尺寸变化/菜单退出恢复同一布局 |
| memory/Skill/MCP 能力不可发现 | 目录、激活与能力协议 | 模型按 schema 发现，缺能力返回可恢复事实，不靠关键词路由 |
| 工具调用缺字段、输出过长 | 工具 schema、结果存储 | schema 与执行入口一致；有界预览不丢完整结果引用 |
| NSSecureCoding 警告 | 原生系统边界 | 先查调用栈和归属，不能无证据归因 Nola 或系统，也不靠隐藏日志解决 |

表中是责任定位，不是所有问题已经证实同一根因；具体失败须绑定实际轨迹和代码版本。

## 性能测量合同

| 指标 | 起止与口径 | 必需分组 |
|---|---|---|
| 首可见输出 | 发送被接受 → 第一段实际可见文本/思考 | 冷启动/热启动、provider、输入规模；区分排队时间 |
| 首 token 链路 | 配置、存储、上下文、网络首字节、解码、提交、渲染各段 | 记录各段与总体，不能把并行耗时直接相加 |
| 压缩耗时与成本 | 触发 → 可用摘要提交 | 热分叉/冷请求、输入/输出/cache read/write、续写次数 |
| 会话切换 | 用户选择 → 目标快照与草稿可交互 | 大小历史、后台流式、冷读/缓存读 |
| 渲染与滚动 | UI 帧耗时、更新频率、主线程阻塞、Part 失效范围 | 各端、长工具结果、快速流式、结束封存 |
| 存储与恢复 | 命令接受 → 提交；重启 → 可恢复状态可见 | 数据量、并发、故障点 |
| 工具吞吐 | 准入 → 实际派发 → 回执提交 | 并行度、等待授权单列、不包含用户思考时间 |

先保存基线的环境、样本数、原始样本、p50/p95、失败率，再为对应平台和场景确定门槛；不能用单次最快结果或固定猜测数字宣布达标。
确定门槛后写入验收配置并锁定，重跑不得为了通过而调整样本或阈值。
无全平台基线时状态为“未建立”，不声称达到任何延迟/帧率目标。

## 验收分层

1. 纯领域：状态机不变量、输入非法组合、确定性重放。
2. 协议：跨语言编解码、未知/缺字段拒绝、错误和取消语义。
3. 事务：真实隔离数据库、CAS、去重、提交边界故障注入、原文 hash。
4. Host：真实执行、返回丢失、平台授权、重复副作用核对。
5. 客户端：Mac/iOS/Android/Web/CLI 各自操作与观察，不能共用 reducer 测试代替。
6. LLM：使用可用真实模型执行任务，审阅完整轨迹、压缩、续写和工具调用，不对题目特化。

所有实现修改完成并审计后集中验证。文档校验不要求启动全量编译；本次文档更新没有执行以上业务验收。
失败记录必须保留，不用摘要“总体通过”覆盖跳过、资源阻塞或尚未触发的真实截断场景。
