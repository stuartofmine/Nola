# 语言服务查询契约

状态：六类查询入口和传输组件已实现；真实模型→clangd→持久化结果的文档符号、定义、引用、hover、实现和工作区符号查询通过（jqcoct6n隔离样本）。覆盖同名绑定、头文件定义、虚方法实现和已打开文档中的工作区符号。不是全仓库索引/跨文件引用覆盖或全平台验收。不能将文本扫描标成语言服务结果。

## 模块与所有权

- Core：具体调用授权、会话/Host 归属、冻结配置。语言服务器启动是进程执行，不因查询名称含 read 就豁免。
- Host LanguageService：按 Host、会话、项目根和配置摘要持有服务器进程，处理 initialize、能力协商、文档同步、查询与 shutdown。不同会话不共享可变文档状态。
- 当前进程生命周期为单次查询：启动、打开目标文档、查询、关闭，不是已实现的跨调用服务池。工作区符号与引用的覆盖范围取决于服务器已有索引及本次打开的翻译单元；空结果不证明整个仓库没有符号。持久化索引/会话级复用仍需单独设计和验证，不以头文件定义验收代替全仓库引用覆盖。
- Wire：仅处理 Content-Length 与 JSON-RPC 帧；不启动进程，不决定权限，不扫描源文件兜底。
- Code query：输入工作区、文件、位置、操作和内容版本；输出服务器来源、位置编码、文档版本、查询结果和截断事实。查询失败与空查询结果必须区分。
- 编辑执行器：未来 rename 返回版本绑定编辑计划，不直接应用服务器响应；每个目标文件走现有写权限、版本核对和执行回执。

## 流程和边界

1. 用户配置服务器命令与语言/项目范围。模型不能传任意服务器命令；不自动安装或下载服务器。
2. 将启动命令、环境和工作目录纳入现有准入流程，使用现有 supervisor 的生命周期、超时与取消。
   服务身份使用 `ProcessHandle` 定位器，解析为绑定准确service_id和调用摘要的 `ProcessInvocation`；另独立声明文档读资源。配置指纹必须与冻结配置一致。服务配置归当前Host/项目管理，恢复会话模型参数不得用模型默认值覆盖本机服务配置或引入另一Host的可执行路径。
3. initialize 后检查 server capabilities；不支持的操作明确返回 unsupported。
4. 以读权限获取文档快照，发送 didOpen/didChange；位置编码明确协商。中文、非 BMP 字符不能把字节偏移当 UTF-16 位置。
   工作区符号查询在支持documentSymbol的服务器上先等待当前文档查询返回，再发送workspace/symbol；两步共用deadline和取消信号，前一步失败不可当成空结果。该同步只针对已打开文档，不宣称整个工作区索引完成；原始工作区查询结果保持不变，不用文档符号合成替代结果。
5. 查询绑定快照版本；响应期间文档变化则标记 stale，不能把旧结果用于自动编辑。
6. 服务器向客户端请求 applyEdit、执行命令或新增工作区时明确拒绝；客户端不实现反向授权旁路。
7. 服务器 stdout 仅允许协议帧；stderr 有界诊断，不注入模型指令。退出、超时、损坏帧不会静默降级成扫描结果。

现有 code_navigation 等扫描入口保持 source_scan 事实。语义后端完成后由显式配置选择，不能返回相同标签掩盖后端缺失。

## 资源上限与验收

传输头最多 8 KiB，单帧最多 8 MiB；按 UTF-8 字节计数。重复长度、缺失长度、溢出和不完整帧拒绝。客户端还须实现调用 deadline、待决请求数量和诊断队列上限；这些不能靠单帧限制替代。

验收覆盖帧连续读取、Unicode、服务器反向请求、取消/超时、文件版本变化、跨会话隔离、同名不同绑定、未安装服务器、能力不支持和异常退出。真实clangd组件样本已验证符号、定义、过期快照拒绝和关闭；不等同全部模型/平台链路验收。
