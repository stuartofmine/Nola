# 远程宿主投影与恢复

简体中文 · [English](REMOTE_HOST_PROJECTION_CONTRACT.md)

远程执行归准入时绑定的源 Host。接收端核对认证身份、Store epoch、原提交与 Run 绑定、来源游标及正文引用，然后在本地事务中保存副本回执、可读投影与同步进度。传输中的临时文字只供现场观察。流结束时须导入并核对源宿主的终态记录。

| 输入或故障 | 接收端行为 |
| --- | --- |
| 尚未确认的提交 | 使用原请求身份向源宿主查询，保留当前草稿和执行状态。 |
| 有提交见证的增量 | 按原会话、消息和 Part 身份更新。只接受与来源游标连续且内容一致的记录。 |
| 网络中断、重复或乱序 | 用原游标补读。相同游标出现不同内容或 epoch 变化时，先核对来源及绑定。 |
| 终态通知 | 核对原 submission、Run、assistant 归属和终态内容。按已提交投影封存消息。 |
| 权限或取消操作 | 将决定发送给原执行者并取得回执。副本上的权限信息仅用于呈现。 |
| 用量上报 | 将结果归到原 Attempt，汇总时避免在来源与副本重复计费。 |

外部编码执行器保留自己的不透明会话 ID，经 Host 协议提交观察。Application 接受效果并形成规范消息。客户端只从投影恢复对话，不根据当前窗口、显示文本或 ID 拼接推导消息归属。

验证时同时检查源状态、断线后的回执和重新打开的界面。将截图或录屏与同一份已提交投影进行比较，检查文字重复、遗漏、闪烁和滚动位移。[Application 命令](../../../../crates/nola-app/src/daemon.rs) · [配对入口](../../../../crates/nola-app/src/web_server.rs)
