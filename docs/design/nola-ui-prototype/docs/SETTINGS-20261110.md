# 当前设置原型 · 2026-11-10

本目录的 HTML/CSS/JS 是可交互浏览器原型，使用合成内容；不调用模型、Host、
OAuth、系统权限、更新下载或 Git 操作。不要输入真实凭据。

## 当前分组

- iOS 风格：首页为通用、模型与账户、专家、Skills/MCP、隐私与数据，共 5 项。
- Android 风格：首页为通用、模型与账户、Skills/MCP、隐私与数据，共 4 项。
- 桌面：首页为通用、模型服务、助手、连接、数据、诊断，共 6 类。
- 通用直接分组外观、通知和软件更新；iOS 演示通知开关原地操作，桌面按平台
  演示登录启动，Android 演示关于信息。原型工具单独收起。
- 资料、知识和记忆从资料进入；计划从活动日历进入并返回活动。
- 普通表面使用实色、细边框和内边距；浮层按需投影。开关切换保留键盘焦点
  和阅读位置，主题切换不重置内容。

生产客户端分组依据见[设置设计记录](../../../../Doc/当前任务/SETTINGS_INFORMATION_ARCHITECTURE_20261110.md)。
原型不等同于各操作系统的像素还原或原生行为验收。
