# Nola 设计规范 · 当前原型

2026-11-11 核对；移动端以 [移动端视觉与交互](MOBILE_UI_DESIGN.md) 为准，桌面沿用现有工作区。此文的桌面及共享身份规范继续有效；移动端使用中性底色、直接排版的回复和轻量设置列表。原型不等于客户端已实现。

## 1. 共同语言，不同任务逻辑
优雅来自清楚的主次、稳定的动作位置和适当留白，而不是堆叠卡片或大面积主题色。手机以会话列表为默认入口，通过活动承接需要回应的事项；桌面是生产力工具，持续对话、内容标签及上下文检查器并存。普通聊天不被强制任务化。

## 2. 色彩与字体
- 页面主底：浅色 `#FFFFFF`，深色 `#000000`。普通正文 `#202020` / `#EEEEEE`，次级文字 `#606060` / `#ADADAD`。
- 层级使用中性色背景、字重、对齐和间距。主题色不用于整页底或通栏装饰。错误/焦点颜色有功能用途。
- 系统无衬线字体栈，优先原生中文字体；正文桌面 16px/26px，手机对话 17px/28px；普通说明段落行高 1.65。
- 正文段落间 12px；列表上下 12px、缩进 20px、相邻条目 8px；正文小标题上 24px/下 12px。元信息 12px/18px，紧凑桌面列表主要条目 13px。
- 标题层级基础为 28/36、20/28、16/24。不要把每一面板都当独立大标题页面。

## 3. 间距与边界
- 一般内容页左右边距：320px 手机 16px，390px 手机 20px，平板中等宽度 32px，宽桌面 40px；这些是内容页基准，检查器/气泡采用各自局部间距，不机械套到每一层。
- 阅读列上限 720px；长文不铺满超宽屏。表格、diff 与资料布局可按内容扩展。
- 桌面全局顶栏固定 48px，只一行。正文三栏从 y=48 开始。全局图标 18px、桌面触区 36px；移动操作触区至少 44px。
- 检查器用紧凑工作列表与分组，不用嵌套卡片墙。独立滚动；宽度 320–480px，紧凑桌面按可用空间限宽。
- 主区内容标签与右工具同栏，标签溢出横向滚动；工具不被长标题挤走。选中标签与内容区视觉相连，不是浮在卡片中的胶囊。

普通内容表面使用语义实色和单层边框，不叠加渐变、内高光或阴影。浮动弹层
按需保留阴影；按下不缩放发送按钮。通用内以标题、间距和内容分组建立层次，
原型调试开关收起，不与产品偏好争夺首屏。

## 4. 主 Agent 发言与专家过程展示
主对话时间线中，**主 Agent（`Nola`）是唯一面向用户发言的角色**（对齐 [多智能体导航契约](../../shared/MULTI_AGENT_NAVIGATION.md)）。专家角色不作为顶层聊天气泡直接发言，也不提供 8 色专家聊天气泡配色。

| 视口 | 助手身份表达 | 用户气泡内边距 | 专家协作呈现 |
| --- | --- | --- | --- |
| 桌面 | 正文上方 `n` 标记与 `Nola` 签名 | 12px 16px | 回复下方的内联过程摘要卡片 +「查看专家会话」只读入口 |
| 手机 390 | 正文上方 18px 标记与 `Nola` 名称 | 12px 15px | 回复下方的内联过程摘要卡片 +「查看专家会话」只读入口 |
| 手机 320 | 正文上方 18px 标记与 `Nola` 名称 | 12px 15px | 回复下方的内联过程摘要卡片 +「查看专家会话」只读入口 |

助手正文直接排布在中性页面底色上，不包裹彩色专家气泡；用户气泡使用主题内中性浅灰（桌面右上圆角 5px、其余 16px；手机四角 20px），不添加漫画尾巴、阴影或双边框。专家子任务的状态、摘要与只读会话入口统一收纳在 `Nola` 回复内的轻量过程卡片（`.expert-process-card`）及右侧「参与者 > 专家会话」中。

## 5. 消息操作与特殊内容
消息级复制、重试、用户编辑重发位于消息内容下方外部，贴合对应内容列。用户操作靠右。行间距 5px、按钮间距 2px，桌面按钮最小高度 32px、手机 44px，图标 14px。始终占位并可访问，不只悬停出现。用户「编辑重发」采用原地截断（`splice`）静默抹除编辑点之后的轮次，并在当前会话重新生成，不派生分支会话或展示「查看原会话」横幅。

错误/等待/流式占位统一归属 `Nola` 主回复，专家子任务的部分未完成状态在内联过程摘要与只读专家子会话中核查。工具授权卡片是内容本身，操作保留在卡片上下文。代码块自身横向滚动；长链接换行，不撑破页面。代码/列表的合成像素测试不表示生产 Markdown 渲染及真实内容链路已完成验收。

## 6. 可访问性与动效
图标提供名称、悬停/焦点提示及中性选中态；不能只看颜色辨识。保留可见键盘焦点、原生单选语义、标准 Tab 路径以及工具/标签的箭头导航。更多菜单可 Escape 关闭并返回焦点。

过渡克制、可中断，支持系统减少动态效果和演示偏好。主题切换不改变层级、内容或流程。浏览器存储与演示限制详见交互规范。

## 移动导航 v24
默认进入对话，四项底栏为对话／活动／资料／设置。列表、会话、详情与外观的当前规范和可操作范围见 [移动端视觉与交互](MOBILE_UI_DESIGN.md)。聊天为全屏会话层，返回恢复列表位置、筛选和草稿；主功能没有“更多”集合页。


## 页面同步与交互状态（2026-11-09）

- 手机输入文字独占满宽一行，下方为附件、模型、按声明显示的推理档位及发送/停止；回放入口放在设置的原型预览，不长期占据输入框上方。
- 设置只有一个页面标题；资料、记忆、计划按实际来源返回。除沉浸式聊天及其所属模型选择流程外，管理页保留四项主导航。
- 桌面左侧只有对话、资源两个主入口（资源一级直达数据中心、自动任务、模型、Skills / MCP、系统访问），顶端提供新建会话图标，不在网页画布内绘制假 macOS 红黄绿窗口栏；检查器的任务、产物、上下文为三个独立一级区域，其中「上下文」拆分为「会话配置」（会话沙盒与作用于主 Agent 后续回复的会话指令）、「上下文预算」（上下文用量、只读会话要点摘要、独立 Wiki 运行笔记草稿与历史召回）、「执行」和「参与者」，消除「上下文 > 上下文」重复层级与双指令输入框混淆。桌面输入栏提供紧凑的「推理强度」（自动/低/中/高）与「权限模式」（谨慎/全部允许）控件，不再重复放置「会话沙盒」胶囊。iOS 与 Android 均开放专家选择与「管理专家」入口。
- 设置分类、文本操作使用中性主题悬停/按下反馈与内边距；复制动作始终无背景和边框。焦点使用语义主题色。
- 更新、清单失败、保存未确认分别表达；重试或核对是明确动作，不能用“成功”关闭未确认的编辑器。所有检查和安装步骤都标注原型演示，不下载或调用真实服务。

实际范围与对比见 [IMPLEMENTATION-COMPARISON.md](IMPLEMENTATION-COMPARISON.md)。

## 业务场景评审视图（2026-11-10）

`scenarios.html` 复用白底／墨色的中性方向，提供目录、平台预览与状态说明。目录和说明只在评审页存在，不能复制进产品页面作为额外导航。桌面正文 14px、手机正文 16px，手机操作至少 48px；320px 下可预览 125% 大字。主动作与次动作区分，拒绝不与允许同时使用实色主按钮；主题焦点和减少动态效果保留。

Host 任务展示来源、执行位置与里程碑；权限完整审阅可原地展开；MCP 的 HTTP／stdio、模型目录启用／选中、五档推理／继承、字体标本分别使用自己的组件。复制只有真实剪贴板写入成功才显示已复制，失败保留手动选择。所有来源、进度、模型与统计均为明确标记的样例，系统栏不自绘假 macOS 窗口控制。

设计依据采用 apple-design 的本地参考：`privacy.md › Requesting permission` 要求“Request permission only when your app clearly needs access”；`motion.md › Best practices` 要求“Make motion optional”。评审页的布局、数值和样例属于本项目设计选择，不是原生平台验收结论。


## 过程标题与文献引用（2026-11-12）

- 运行中展示当前活动，步骤间为“正在处理中”；展开历史也不提前变成“执行过程”。已结束历史使用中性标题，具体失败保留在对应步骤，技能未完成保持未完成。
- 正文和表格中的内联外部链接同样使用小号灰色，不随正文或表头继承粗体蓝色；原链接目标保持不变。
- 文献置于回复末尾，以编号、标题及必要定位构成列表，默认三条；展开/收起为文字动作。引用不铺卡片背景、不逐条加箭头。技能统计只在信息入口中显示，不在正文放运行 ID、原始毫秒或协议字段。
- 原型引用为 12px 主题辅助灰色；生产客户端使用各自可缩放的 caption/bodySmall 与语义主题色，不强制同一物理字号。灰色文字须保持普通小字至少 4.5:1 对比，触控区域独立于视觉字号保留。
- [独立预览](../reply-preview.html)与完整桌面/手机比较会话共用 `reply-presentation.js`、`reply-presentation.css`。31 条来源、耗时、状态切换均为合成样例，不证明真实研究或验收完成。

生产行为与原型区别见[客户端对比](IMPLEMENTATION-COMPARISON.md)，已执行证据及系统限制见[验证记录](VALIDATION.md)。
