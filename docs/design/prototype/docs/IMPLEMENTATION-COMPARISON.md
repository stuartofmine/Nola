## 移动视觉设计更新（2026-11-11）

本轮移动原型改用中性底色、浅灰用户气泡与直接排版的助手正文，收紧输入工具栏，设置改为平面分组列表；保留 iOS 和 Android 导航及触摸尺寸差异。新增 `mobile.html` 用于桌面评审手机布局，切换主题、平台与宽度不丢失草稿。具体规范见 [MOBILE_UI_DESIGN.md](MOBILE_UI_DESIGN.md)。

后续原生实现已同步中性颜色、助手完整阅读宽度、用户圆角气泡、输入边界、会话列表标题/预览和设置平面分组。主会话统一由 `Nola` 发言，专家作为内联过程摘要与只读专家子会话呈现。原型截图仍不能代替原生产品验收；两类证据分开记录，详见 [验证记录](VALIDATION.md)。

依据当前本地工作树的多平台逐页验收（本地工作记录，不随仓库分发）和现行[交互规范](../../shared/CONVERSATION_UI_DESIGN.md)。本次修改实际可操作原型，不把修复前的客户端缺陷当作设计标准，也不把原型演示当作生产验收。

## 全业务场景补充（2026-11-10）

本次新增 68 项／220 状态的独立评审入口与结构化清单，并替换旧 CSV 的重复条目和过时导航。Web 当前 14 路由全部关联，新增路由未补场景时同步检查失败。原有完整原型只增加预览入口，没有改生产客户端。

宿主机权限设计依据本轮实际 Android 修复：安全审阅文本贯通，缺失时不允许操作；长任务场景对齐已验证的 Web 200 步／两次压缩、Host 重启及 Android 两分钟强停客户端后恢复链路。原型是合成状态，不将真实测试结果扩大为所有平台已通过。详见[实际宿主机流程](../../shared/HOST_CONNECTION_WORKFLOW.md)。

## 保留的差异

- iOS、Android、Mac、Web 的信息布局和控件样式不同，原型用一个共享浏览器系统说明行为。切换“iOS / Android”只切换原型风格，不能代替两个操作系统的验收。
- 资料页可打开演示编辑表单；记忆/知识目录重点展示来源关系，未模拟全部生产编辑命令、事务、并发冲突和持久化。
- 更新结果、能力读写、错误、安装步骤、模型与消息均为合成状态。原型不连接 GitHub、Host、模型、OAuth、系统权限或真实文件；检查中/成功不能作为真实请求凭证。
- 不把未签名测试环境的 Health entitlement 错误画成正式常驻产品状态。权限、格式不兼容和真实错误由生产客户端各自呈现。
- 原型中的原地编辑重发、会话指令和 Wiki 草稿仅在本次页面内保留；刷新恢复演示数据。浏览器返回历史的全部组合、原生侧滑、输入法、屏幕阅读器及全字号仍非本轮证据。
- 旧外部 Site 未在本次发布；当前资产是仓库 `index.html` 和同目录脚本/样式。

## 2026-11-11：侧栏与过程展示同步

本轮原型对照已修改的 Mac/Web 侧栏：去掉桌面历史活动图标与假 macOS 窗口红绿灯栏；桌面「资源」一级直达数据中心、自动任务、模型、Skills / MCP 与系统访问；概览不再复制导航；浏览器归入执行；「上下文」拆分为「会话配置」与「上下文预算」，知识摘要与 Wiki 草稿默认收起。全局页面隐藏会话检查器，工作区更改与浏览器演示状态不跨会话串用。流水状态模拟文字流光，并提供减少动态效果的静态结果。

手机仍保留自己的原生导航模型，不因桌面入口删除而假装移除待回应事项。原型中的目录、浏览器、任务状态和草稿仅是本页演示数据；通过原型回放不能说明客户端网络、授权或真实模型验收通过。
