## 全业务场景补充（2026-11-10）

本次新增 68 项／220 状态的独立评审入口与结构化清单，并替换旧 CSV 的重复条目和过时导航。Web 当前 14 路由全部关联，新增路由未补场景时同步检查失败。原有完整原型只增加预览入口，没有改生产客户端。

宿主机权限设计依据本轮实际 Android 修复：安全审阅文本贯通，缺失时不允许操作；长任务场景对齐已验证的 Web 200 步／两次压缩、Host 重启及 Android 两分钟强停客户端后恢复链路。原型是合成状态，不将真实测试结果扩大为所有平台已通过。详见[实际宿主机流程](../../shared/HOST_CONNECTION_WORKFLOW.md)。

## 保留的差异

- iOS、Android、Mac、Web 的信息布局和控件样式不同，原型用一个共享浏览器系统说明行为。切换“iOS / Android”只切换原型风格，不能代替两个操作系统的验收。
- 资料页可打开演示编辑表单；记忆/知识目录重点展示来源关系，未模拟全部生产编辑命令、事务、并发冲突和持久化。
- 更新结果、能力读写、错误、安装步骤、模型与消息均为合成状态。原型不连接 GitHub、Host、模型、OAuth、系统权限或真实文件；检查中/成功不能作为真实请求凭证。
- 不把未签名测试环境的 Health entitlement 错误画成正式常驻产品状态。权限、格式不兼容和真实错误由生产客户端各自呈现。
- 原型中的编辑分支和 Wiki 草稿仅在本次页面内保留；刷新恢复演示数据。浏览器返回历史的全部组合、原生侧滑、输入法、屏幕阅读器及全字号仍非本轮证据。
- 旧外部 Site 未在本次发布；当前资产是仓库 `index.html` 和同目录脚本/样式。
