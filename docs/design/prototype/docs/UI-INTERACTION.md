## 全业务状态审阅入口（2026-11-10）

新增 [scenarios.html](../scenarios.html) 与 [68 项业务清单](BUSINESS-SCENARIOS.md)，覆盖 220 个可导航状态、正常／失败／等待／恢复分支与六个平台视角。目录与状态跳转是评审工具，不是生产客户端的新导航。原型通过真实页面按钮推进样例、取消确认、保留失败草稿与恢复浏览器历史；适用平台不表示已经落地或通过原生测试。字段与状态按平台／场景隔离，仅存当前页面内存。既有完整原型继续承载完整会话与工作区操作，两入口互通。

## 1. 双端任务架构
### 手机（宽度不超过 700px）
默认进入**对话列表**，主导航为**对话、活动、资料、设置**。会话列表紧凑显示标题、两行摘要、时间、草稿及待回应状态。活动汇集当前 Host 可见的待授权、待补充和执行结果；资料保留来源与访问范围。

打开聊天后使用全屏会话层：返回、可点击的会话身份、搜索；底部保留模型入口、附件、原生多行输入和发送／停止。会话详情直接列出参与者、模型、执行位置、上下文、资料和任务入口，不用“更多”集合页。切换会话保留独立草稿和阅读位置。聊天中暂时隐藏主导航是本次 IM 沉浸式取舍，返回始终可见，原生须支持系统返回手势。

仅新增文字渐显；上翻暂停自动跟随，底部新内容入口可恢复。减少动态效果遵循系统及预览开关。完整动效和所有权约束见 v24 文档。

### 桌面（宽度至少 701px）
应用内容只有一条 48px 全局顶栏，下面直接是左列表、主内容与右检查器。macOS 另保留系统标题栏及系统关闭/最小化/缩放控件；它不是另一条产品导航。顶栏左侧为全局区域图标（对话、资源），中间为浏览器式内容标签及新建对话，右侧为任务、产物、上下文三个具名工作工具组。没有额外品牌栏、会话标题栏、画布模式或第二排工具导航。

- 左类别和搜索只改变左栏列表，不替换主内容。
- 右工具打开/定位同一检查器的独立展开区段，不替换当前内容标签；不设置面板内页选择器或二级返回栈。
- 明确选择另一会话才切换会话上下文。
- 点击右栏文件/产物先选择局部详情；显式“在标签页打开”才展示完整内容。
- 对话是常驻、不可关闭的首标签。对象以稳定类型/ID 去重；重复打开聚焦现有标签。
- 对象关闭返回左邻标签；标签支持键盘操作。长标题横向溢出在标签区域内，工具固定在同栏右侧，不换行。
- 每个会话拥有自己的标签、输入草稿和详情滚动位置。回到会话时恢复该会话对象集合并选择对话标签。
- 当前编辑器是明确保存/取消的模态表单，不是标签内未保存编辑器；不宣称实现任意标签草稿关闭确认。
- 检查器独立滚动、键盘可调整宽度 320–480px；紧凑桌面有上限，1000px 视口时最大 380px。

### 当前输入与侧栏补充

手机输入采用满宽多行文本及紧凑底栏（附件、模型、实际推理档位、发送/停止），有内容时再显示附件/参与者。推理五档按声明完整保留，不增加重复三档菜单。边框/焦点跟随主题；复制动作无常驻边框/填充。提示词模板归入模型设置，作用范围仍由原会话或模型配置合同明确。

检查器各区段可独立展开，知识/Wiki/召回默认收起并原地展开；展开不清草稿、不重启 Run。概览不再复制分组跳转或产物列表；计划、目标、执行任务分别归位，浏览器属于执行。当前活动可直接显示，历史调用收在中性“执行过程”入口中，具体步骤的失败不作为整个思考过程的结论。手机侧栏/面板保留按钮和系统返回，滑动支持取消与方向适配，动效尊重减少动态效果。上述布局与检查器展开已接入当前原型；系统手势、真实运行与完整配置持久化仍按验证边界区分。

### 当前设置分组

- 手机首页在 iOS 与 Android 上一致保留通用、模型与账户、管理专家、Skills 与 MCP、隐私与数据（共 5 项），输入框 `+` 面板同样提供选择专家与管理专家入口。
- 通用直接分组外观、通知、软件更新，不再列独立外观/通知/更新分类页。
  iOS 演示通知开关原地切换；Android 显示通知中心及系统权限说明入口。
- 资料、记忆和知识从资料入口访问；计划从活动的日历入口访问并返回活动。
- 桌面保留通用、模型服务、助手、连接、数据和诊断；通知并入通用，启动选项
  明确是本机选项预览。检索/记忆默认项仍属于助手，不混入外观偏好。
- 演示控制单独收起。所有授权、更新和连接都是原型说明或合成状态，无真实操作。

## 2. 消息、专家与输入
主对话流中仅保留用户与主 Agent（`Nola`）两类发言者。专家作为受控子任务执行者协助 `Nola`，不在主会话直接渲染独立专家聊天气泡，也不提供「气泡颜色」或 8 色专家预设选择器。

当会话启用协作专家时，`Nola` 统一汇总回复并在消息内附带可展开的「专家协作」内联过程摘要卡片，展示各专家子任务状态与摘要，并提供只读「查看专家会话」入口打开对应专家子上下文。专家库支持查看内置角色模板、创建/编辑自定义专家的模型、推理档位与角色模板。

桌面输入框底部工具栏与原生 Mac 对齐，提供紧凑的「推理强度」（自动 / 低 / 中 / 高）与「权限模式」（谨慎 / 全部允许）胶囊控件；「会话沙盒」收敛至右侧检查器「上下文 > 会话配置」，不在输入栏重复放置。发送产生本地模拟回复，可停止；输入草稿随会话隔离，侧栏或内容标签切换不覆盖草稿。

### 气泡外消息操作
复制、失败重试位于回复下方外部，用户消息也有气泡外「复制 / 编辑重发」。按钮在手机始终可发现，不依赖悬停，不因悬停改变布局。工具授权/补充输入属于工具内容，仍在原上下文内，不强行移出。

复制只有在系统剪贴板写入成功后才提示成功；被拒绝或不可用时显示选中文本的只读手动复制窗口。

### 用户编辑后重发
1. 进入编辑窗口，原消息与输入区未发送草稿均不修改。
2. 取消保留原状；空白不可提交。生成未结束时禁用编辑并解释原因，可先停止/等待。
3. 「保存并重发送」在**当前会话原地截断（`splice`）并静默抹除后续轮次**：用修改后的文本替换该条用户消息，移除其后的全部消息，再由 `Nola` 在当前会话重新生成回复；不创建分支会话，也不显示「查看原会话」横幅。
4. 沿用原用户消息的协作专家与会话配置快照；若启用了协作专家，重发后的 `Nola` 回复内联附带更新后的专家协作过程摘要。
5. 编辑点之前的历史、会话 ID、标题和底部输入框未发送草稿保持不变。所有重发结果仅保留在本次页面内存，刷新恢复初始演示数据。

## 4. 二级功能及数据含义
会话知识点、独立 Wiki、压缩摘要/历史召回、个人长期记忆是四种不同对象。知识点能编辑并演示并发冲突/保留草稿；Wiki 独立编辑；回忆区检索历史；长期记忆提供类别、依据和置信度。

资料支持添加/编辑/访问策略/模拟检查/删除确认；模型提供本地/API 配置演示与连接失败恢复；计划提供配置、启停、运行一次和历史；活动展示需关注、结果、授权与补输入恢复；Skills/MCP/系统访问提供范围与模拟开关；设置分组展示外观、通知、检索/记忆默认、Agent、隐私、诊断。桌面 Git 审阅的提交与推送各有确认，但从不运行真实 Git。

## 5. 持久化、异常与边界
- 浏览器存储：主题、减少动态效果；无账号/跨端同步。
- 页面内存：会话/原地重发/草稿、版本编辑、工具授权、计划、资料及管理演示；刷新恢复演示数据。
- 保存/取消、拒绝/允许、失败/重试、等待补输入、空态都有不同语义，不把所有异常统一成“成功”。
- 手机/桌面导航状态独立，跨断点不把手机会话列表直接放大成桌面页面。
- 所有演示内容均为样例；生产能力依据与实现程度见根目录能力矩阵。原型没有接入真实 Host、调度、OAuth、系统权限、并发推理或同步。

## 6. 工作归属与执行尝试（2026-11-02 仓库原型更新）

桌面保留现有工作区结构；手机按 v24 会话优先，活动详情增加工作归属、本次执行、执行位置与上下文范围；目标进度把执行状态与目标验收分开。进行中、等事件、等人、未完成、已完成分别表达，详情不自行授权或接管执行；回到来源会话使用现有精确操作。等事件是记录状态示例，不承诺通用订阅调度已经实现。目标演示可结束本次执行并保留未完成要求，明确继续才开始下一次；没有伪造 Goal 完成。

原型只演示本页状态，显示的 Mac 执行位置为虚构样例。生产 CLI/macOS 原生有自动 Goal Host，iOS/Android 也可在已建立冻结配置的本机会话中、App 可执行期间逐轮推进；配对 Host 仍由来源端执行；不显示未实现的手机本机永久 Goal 调度或跨 Host 接管。子任务只传任务 brief 和可访问资料引用；会话原文、摘要、长期记忆与 CodeMemory 仍属不同数据。使用现有文本层级、分隔与共享 SVG，不新增图标框架。

本批能力说明：macOS 原生实际复用 Host 的 Goal 循环与后台唤醒，不能把它归为只观察；iOS/Android 不承诺永久后台 Goal。子模型先支持 iOS 同连接且生成策略相同的不同 HTTP 模型；界面不提供跨账户接管按钮。相关追问保留原工作归属，已停止工作不自动复活；终态后明确请求的“派生续作”创建新的 Task 和执行记录，原 Task/Run 保持终态；不能把它标作同一业务任务的恢复。进行中追问和等待恢复仍保留原身份。

本机 Goal 进度与来源 Host 明确区分：手机详情提示仅在 App 可执行期间推进，后台暂停/未决保持真实状态；不把系统后台保活作为设计承诺。Start 使用已建立的会话执行配置，当前选择改变时先建立新普通 Run；未配置新会话不展示伪执行成功。原轮已 sealed 但尚待验收时，仍是原执行记录的验收，不是新任务。

Goal Host 接线：所有平台都消费同一 Core step 的 execute_run/wait/needs_user/terminal 指令；浏览器只观察，实际执行归所连 Host。页面中的等待、继续和停止仍映射已有 Core control，不由客户端推断续轮。

### 未配置模型（2026-11-03）
未配置模型的新对话，中央直接显示「选择模型，开始对话」与「配置模型」主按钮；已有聊天内容时，配置引导放在输入区旁。不把入口藏在更多菜单的未配置子菜单里。草稿可编辑并保留，普通发送在选好模型前禁用；点击打开已有模型配置页，返回聊天后草稿仍在。已有模型时输入区直接显示当前模型选择。原型可通过 `?models=empty` 查看无模型状态；示例配置只更新演示数据，不联网、不保存密钥。

### 会话入口直接可见（2026-11-03）
不使用通用「更多」菜单：专家、执行单元、执行位置和模型在输入区上方直接可见，输入栏底部提供推理强度与权限模式紧凑选择；会话沙盒统一收纳在右侧「会话配置」。搜索与侧栏开关在顶栏，设置留在左栏。右侧用三个具名入口组织工具：任务（概览、进度、目标）、产物（审阅、产物）、上下文（会话配置、上下文预算、执行、参与者）。入口保留名称和当前分组选中态，组内在同一检查器原地展开，不用页选择器或无名“更多”。内容标签在窄窗口横向滚动并定位当前标签，不收进溢出菜单。值选择器仍使用有明确名称的原生菜单，不承担无关功能的聚合入口。


## 7. 更新与失败恢复

设置可进入软件更新页：未检查、检查中、检查失败、发现更新、已是最新、数据格式不兼容。所有结果为本页演示。格式不兼容时不提供安装入口；安装步骤只预览，不下载、校验或打开程序。

能力清单失败保留已配置对象，提供重新读取，不渲染空清单冒充成功。MCP 编辑器可演示不完整保存回执：保留输入、阻止自动重复提交，重新读取演示已保存值后再由用户明确保存。关闭原型后不保留这些数据。

推理选择在模型详情与移动端按模型声明展示 actual effort（五档虚构演示模型提供 none/low/medium/high/xhigh 与继承），桌面输入栏提供会话级「推理强度」（自动/低/中/高）与「权限模式」（谨慎/全部允许）紧凑控制。选择模型默认与本段会话模型分别作用。手机与桌面编辑重发统一采用原地 `splice` 截断后续轮次并在当前会话重发，不覆盖输入草稿；复制失败复用只读手动复制窗口。


ChatGPT 账户引导与原生 Mac 对齐：开始登录后自动打开浏览器，授权成功后自动保存账户，随后由用户选择模型。原型用一次明确的“授权成功并自动保存”模拟系统结果，没有额外的手动保存步骤；所有状态仍为本地演示，不发起真实登录或模型调用。

## 侧栏同步（2026-11-11）

桌面左侧仅保留对话和资源两个图标，设置在列表底部只有一处。资源一级列出数据中心、自动任务、模型、Skills / MCP 和系统访问；数据中心内部同时保留资料、长期记忆与自动任务分类。全局管理内容打开时隐藏会话检查器，顶栏工作工具可返回当前会话并定位对应区段。

右侧概览保留当前状态、来源 Host 和工作区，演示切换工作区不切换会话；「上下文」组拆分为「会话配置」（会话沙盒与作用于主 Agent 后续回复的会话指令）和「上下文预算」（未测量/未知的用量与缓存、诊断详情、只读会话要点、独立 Wiki 运行笔记草稿与历史召回），消除双文本框混淆。执行记录默认折叠，浏览器连接按会话隔离；参与者集中展示 `Nola`、协作专家及只读专家子会话。

处理中用固定文字底层和 2.4 秒单色亮带表现流动，文字不移动。减少动态效果时仅显示静态文字。手机仍使用自己的四项主导航，活动承接待回应事项，与已移除的桌面历史活动图标分开。


研究回复的过程标题在整轮运行中保持当前活动，步骤间显示“正在处理中”，展开历史不提前变成结束标题。来源为小号灰色编号列表，默认三条，以文字按钮展开全部；详情与统计按需查看，正常回复不展示原始运行 ID 或毫秒。桌面与手机完整原型和 reply-preview.html 共用 reply-presentation.js；演示状态不构成真实执行证据。
