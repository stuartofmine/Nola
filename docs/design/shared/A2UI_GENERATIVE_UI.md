# A2UI 生成界面交互要求

更新：2026-10-28。本文件为交互要求，不作为完成证明；实施记录已归档，任务状态见当前入口（本地工作记录，不随仓库分发）。关联阶段实施记录（本地工作记录，不随仓库分发）与[运行时契约](../../architecture/模块/13-客户端投影/A2UI_RUNTIME_CONTRACT.md)。本文件细化现有设计系统，不创建另一套应用外壳。

## 会话与卡片

生成界面嵌入稳定 Message/Part 位置，沿用现有字体、间距、主题、圆角和选中边框。模型决定语义内容与允许的布局，不能修改导航、输入栏、权限 UI 或全局主题。局部数据更新只更新相关节点；不清空消息、不替换整个列表、不闪现占位后再恢复。

移动端保持 IM 路径：会话列表 → 选择会话进入详情 → 左上角或左缘返回手势；卡片内部横向操作不得抢走系统返回手势。只有一个新会话入口；Agent 管理不能额外建聊。返回后恢复列表位置；重进恢复卡片已提交状态，未提交草稿按 owner 隔离。

Apple 共享渲染组件与状态呈现；系统导航/窗口行为可以不同。Android 使用原生输入和 Compose 组件。Web 使用指定 `a2ui-svelte` 的受控适配及 Nola design tokens，不原样照搬 demo 的外壳与主题。

## 内容表达与权限

`render_ui` 发布的是 Core 校验后的会话内表单和布局，不是地图、画布或通用绘图器。关系图、流程图、时序图和路线拓扑使用客户端已有的 Mermaid 图形渲染；不得用空格、文字箭头或多张说明卡片冒充图形。路线拓扑必须说明其不表示比例或地理方位；需要真实地图时使用可用的地图或图形产物能力。绘制前核对事件、时间、分支、方位及箭头语义，不能依赖“仅供示意”掩盖相互矛盾的表达。

纯 UI 发布只更新当前会话内已验证的界面，不执行按钮背后的业务操作，因此不触发普通谨慎模式确认。显式拒绝规则仍然生效；表单按钮引出的文件修改、联网、外发、敏感读取等动作继续由 Core 单独准入。此规则只作用于 Core 自有发布器，不扩展至同名的插件、MCP 或任意工具。

Surface revision 是并发一致性和恢复的内部凭据，不作为聊天中的可见版本标签。已经显示完整卡片时，不再附加重复的“表单版本”入口。当前卡片不可读时可提供“查看内容”的只读恢复入口；历史 revision 读取、归属检查与不可交互限制保持完整。

## 状态与反馈

| 状态 | 呈现与操作 |
|---|---|
| 尚未收到完整依赖 | 单卡片稳定占位，不展示可点击的半成品表单 |
| 可交互 | 可读标签、整行有效点击区域、清晰焦点；选择使用边框与平滑过渡 |
| 提交中 | 该动作显示进度并防连点，其余可操作内容保持稳定 |
| 权限等待 | 可信宿主权限面板显示真实动作/范围；卡片仅显示等待 |
| 校验失败/冲突 | 字段附近提示并保留输入；冲突明确选择刷新或重新提交，不暗中覆盖 |
| 离线/提交未知 | 保留卡片，查询权威回执；不要显示“再点一次”制造重复副作用 |
| 不支持/已失效 | Core 提供可读摘要和原因，禁用对应操作；不得回退执行另一协议 |

卡片完成不等于整个任务完成；长任务使用现有 Run 状态与取消入口。多 Agent 卡片显示来源成员，状态按各自 owner 更新，不能共享一个全局 loading。

## 输入、滚动与层级

输入组件稳定 identity；中日韩组合输入、粘贴、选择文字与实时更新同时发生时不丢焦点。模型更新不能覆盖用户尚未提交的编辑。提交前合并本地编辑，以 Core 返回的校验结果为准。隐藏和删除正在编辑的字段必须先处理草稿冲突，不静默丢字。

新节点的展开/收起使用局部尺寸和透明度过渡；不要整页 spring 或每个流式 token 重新进场。只有用户处于跟随底部状态才自动滚动；阅读历史时保持锚点。长卡片采用有界布局，避免把输入栏推到屏幕外。

Web 下拉、提示和对话框使用现有统一 overlay/portal 层级：不被卡片 overflow 裁剪，不遮断聊天输入，不叠加独立 z-index 体系；跟随锚点、视口碰撞处理、Escape/点击外部关闭、焦点回归和 modal focus trap 必须验证。移动键盘、横竖屏、大字号与窄屏下不得溢出关键按钮。

标签与图标属于同一个点击目标；表单标签能聚焦对应输入，选择行可整行点击。复用现有平台触控尺寸规范、语义 accessibility role、读屏错误提示和键盘顺序，不把图标涂大当作扩大命中区域。

## 真实验收场景

四端使用同一份表单、列表重排、详情与任务卡夹具验证语义；无需追求像素相同，但数据、状态、可用动作必须一致。截图只证明外观，不能证明动作接通。

必须现场操作：真实模型生成 → 输入（含 IME）→ 提交 → 权限批准或拒绝 → 业务结果更新 → 切换会话 → 返回 → 重启恢复。另覆盖两 Agent 同名卡片、长任务取消、离线后回执查询、旧卡片按钮、Web 层级遮挡及移动返回手势。证据记录版本、平台、截图/录像和动作回执；未运行场景标为未验证。
