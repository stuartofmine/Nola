# 会话右侧检查面板

核对：2026-11-08，本地当前工作树。此页定义已接受的检查器交互；原型未同步的切页演示不覆盖本契约。源码与跨端边界见[客户端交互与配置](../../architecture/模块/13-客户端投影/CLIENT_INTERACTION_AND_CONFIGURATION.md)。

## 单一面板、原地展开

桌面只有一个右侧检查器。任务、产物、上下文等顶栏入口打开或定位同一面板中的分组，不替换中央对话、内容标签或左侧列表。面板内不再提供页面选择下拉框、二级工具页或返回栈。

- 概览、审阅、产物、进度、目标、执行、参与者和上下文是可独立展开的区段，允许同时展开多个。Web 另有会话设置区段。
- 点击分组标题原地展开/收起；从顶栏或概览定位工具时展开对应区段并滚动到它。面板有固定标题和明确关闭动作。
- Mac 知识点、Wiki、历史召回也在原地展开，取消内部互斥标签。关闭一项不覆盖另一项的编辑内容。
- 整个面板使用一个主要滚动区域；长代码、文档阅读器可有自身必要的滚动，但不让每个工具区都成为固定高度滚动窗。
- 预设提示词归入模型设置。Mac 在会话模型设置中选择模板，保存前属于编辑器草稿；iOS 在会话设置的模型区选择并即时提交。移动位置不改变模板或会话的持久所有者。
- 模型连接、账户、密钥和全局默认仍由模型中心管理；从会话设置访问它们须明确作用范围。

手机使用独立会话列表、原生面板/底部表单或 Web 抽屉，不缩小桌面三栏。iOS 资料详情在列表内展开；不要求 iOS/Android 已具有桌面全部检查器分组。

## 内容与业务事实

| 语义 | 内容 | 边界 |
| --- | --- | --- |
| 概览/进度/目标 | 当前阻塞决定、真实目标状态、计划、requirements、工作记录、下一步 | 不给普通闲聊自动创建 Goal，不用工具次数或耗时估算完成百分比 |
| 审阅/产物/资料 | 文件、附件、引用、差异和已有阅读入口 | 选中局部详情不切换中央标签；完整对象由显式打开动作进入阅读器 |
| 上下文 | 工作目录、用量、知识点、Wiki、召回、数据源和浏览器上下文 | 不混入模型账户或复制全局配置；未知用量不是零 |
| 执行/参与者 | 归属于原会话、Run、成员的执行记录与控制 | 成员级配置必须指定成员，不拼接多个成员为一个虚假 Goal |
| 会话模型设置 | 当前模型覆盖、推理档位、模板、采样与输出限制 | 不增加与原生 effort 重复的“简洁/均衡/详细”选择器 |

`reported_done` 不是验收完成。未知状态显示可辨认文字，失败与空计划分开，重试就近可见。待授权、待回答和需要用户处理的失败在正文仍可发现，不得因面板折叠而隐藏唯一操作入口。

## 展示与生命周期

折叠集合、定位目标、滚动和动效属于客户端展示状态，不写入模型 prompt，不触发任务执行。消息、计划、Goal、配置与统计来自原有 Core/Application 投影，不建立检查器专属业务副本。

读取和编辑至少绑定 authority/Host、conversation、generation；成员内容再绑定 participant/Context/Run。切 owner 立即隔离旧内容，迟到结果不得写入新 owner。同一 owner 刷新失败保留最近成功内容及未提交草稿，并显示原位错误。

Web 首次展开相关区段时才挂载对应进度观察组件；已经访问的区段收起后保留组件与草稿。不能将“折叠”文档化为所有平台都已停止轮询。Mac 的读取任务遵循实际视图挂载生命周期，具体间隔不由本页另设一套常量。面板关闭、窗口隐藏和 Run 停止观察不是业务取消。

正文不继承检查器开合产生的整树布局动画，不重挂载消息列表，不重播历史流式内容。开合动画简短、可中断；减少动态效果时关闭位移与装饰动画。主题边界、焦点和悬停使用语义色，不硬编码蓝色。

- Mac：`MacChatInspectorView.swift`、`MacInspectorKnowledgeView.swift`、`MacInspectorInteractionTests.swift`。
- iOS：`IOSConversationInspector.swift`、`ChatMoreSettingsSheet.swift`、`ChatNavigationGestureBridge.swift`。
- Web：`Chat.svelte`、`ChatResponsivePanel.svelte`、`panelSwipe.test.ts`。
- Android：`ConversationInspector.kt`、`ChatMoreSettingsSheet.kt`、`ChatScreen.kt`。
