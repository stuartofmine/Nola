# 会话右侧检查面板

核对：2026-11-17，本地当前工作树。此页定义已接受的检查器交互；原型未同步的切页演示不覆盖本契约。源码与跨端边界见[客户端交互与配置](../../architecture/模块/13-客户端投影/CLIENT_INTERACTION_AND_CONFIGURATION.md)。

## 一级区域、扁平滚动

桌面只有一个右侧检查器。Mac 顶部三个图标分别切换任务、产物、上下文三个独立的一级区域，不能把它们实现成同一长列中的三个滚动定位点。切换区域不替换中央对话或左侧列表；各区直接展示扁平分组（无外层 9 组折叠手风琴），并各自保留滚动与未提交编辑。面板内不再提供页面选择下拉框、二级工具页或返回栈。Web 当前保留同面板原地展开布局，不能把 Mac 的完成状态写成 Web 已切换独立区域。

- 任务区包含当前执行与待办计划、目标控制与完成要求（无目标时支持原地设定目标）、协作参与者及只读「专家会话」；产物区包含生成产物、会话资料与工作区变更审阅（显式进入独立审阅窗口）；上下文区包含长期记忆模式与检索开关、上下文用量（详细信息无 SHA-256 摘要哈希）、原始消息/摘要计数胶囊与默认收起并可独立展开的「知识点 / 会话 Wiki / 会话回忆」、会话数据源，以及仅在 Chrome 扩展未连接或报错时才显示的「托管浏览器」。当前区域内容彼此分隔，其他区域的内容不混排进当前区域。
- Mac 知识点、会话 Wiki 与会话回忆也在各自区域内原地展开，取消内部互斥标签。关闭一项不覆盖另一项的编辑内容。
- 每个一级区域使用一个主要滚动表面，切换时保留其阅读与编辑状态；长代码、文档阅读器可有自身必要的滚动，但不让每个工具区都成为固定高度滚动窗。
- 会话提示词模板与采样参数归入模型设置（本会话模型参数 / 独立模型中心）；桌面输入栏文件夹选择统一使用「临时工作区」代替旧工程术语「会话沙盒」，不在检查器上下文重复放置沙盒与指令框。
- 模型连接、账户、密钥和全局默认仍由独立设置或模型中心管理；从会话设置访问它们须明确作用范围。

手机使用独立会话列表、原生面板/底部表单或 Web 抽屉，不缩小桌面三栏。iOS 资料详情在列表内展开；不要求 iOS/Android 已具有桌面全部检查器分组。

## 导航与信息去重

左侧承载全局功能，右侧承载当前会话。桌面左侧统一列出「对话 / 专家与技能 / 自动化中心 / 记忆与数据源」四项主导航，与常驻对话搜索和置顶/最近会话列表共存，底部提供唯一独立的「设置」窗口入口（取消顶栏「对话 | 资源」双图标切换与伪浏览器管理标签栏）。记忆与数据源内部提供长期记忆、来源与使用记录切换；专家与技能集成「专家 | 技能 | MCP」分段。系统访问、诊断与模型服务收归独立设置窗口。

右侧检查器移除「工作概览」与外层手风琴，取消重复的跳转按钮或产物列表。进度显示待办计划与当前执行，目标显示目标控制、完成要求和工作记录；iOS 目标控制只在目标面板出现。Mac 上下文中的知识编辑器默认收起，只有显式定位某项才自动展开它。

会话内的权限模式、资料覆盖和错误恢复继续保留。全局模型、Skill/MCP、系统访问与诊断由全局入口管理；右侧不再复制整套管理导航。上下文占用和缓存命中率直接可见，请求/尝试编号与片段诊断收进原地详细信息，不移除其可核查性。

## 内容与业务事实

| 语义 | 内容 | 边界 |
| --- | --- | --- |
| 任务 | 当前执行与待办计划、目标控制、完成要求、工作记录、协作参与者与只读专家会话 | 不给普通闲聊自动创建 Goal，不用工具次数或耗时估算完成百分比；成员配置不跨成员拼接 |
| 产物/审阅/资料 | 生成产物、附加资料、Git 变更文件、差异预览与独立审阅窗入口 | 选中局部预览不跳转主工作区；完整代码审阅由显式动作打开独立窗口 |
| 上下文 | 长期记忆与检索开关、上下文用量（详细信息无哈希）、原始消息/摘要计数、知识点、会话 Wiki、会话回忆、会话数据源、条件展示的托管浏览器 | 不混入模型账户或全局设置；未知用量不是零；托管浏览器在健康已连接时隐藏 |
| 会话模型设置 | 当前模型（含外部编程代理与已配对 Host）、推理档位、模板、采样与输出限制；文件夹选择默认「临时工作区」 | 未配置远端 Host 时隐藏 Host 概念；不增加重复的“简洁/均衡/详细”选择器 |

`reported_done` 不是验收完成。未知状态显示可辨认文字，失败与空计划分开，重试就近可见。待授权、待回答和需要用户处理的失败在正文仍可发现，不得因面板折叠而隐藏唯一操作入口。

## 展示与生命周期

折叠集合、定位目标、滚动和动效属于客户端展示状态，不写入模型 prompt，不触发任务执行。消息、计划、Goal、配置与统计来自原有 Core/Application 投影，不建立检查器专属业务副本。

读取和编辑至少绑定 authority/Host、conversation、generation；成员内容再绑定 participant/Context/Run。切 owner 立即隔离旧内容，迟到结果不得写入新 owner。同一 owner 刷新失败保留最近成功内容及未提交草稿，并显示原位错误。

Web 首次展开相关区段时才挂载对应进度观察组件；已经访问的区段收起后保留组件与草稿。不能将“折叠”文档化为所有平台都已停止轮询。Mac 的读取任务遵循实际视图挂载生命周期，具体间隔不由本页另设一套常量。面板关闭、窗口隐藏和 Run 停止观察不是业务取消。

正文不继承检查器开合产生的整树布局动画，不重挂载消息列表，不重播历史流式内容。开合动画简短、可中断；减少动态效果时关闭位移与装饰动画。主题边界、焦点和悬停使用语义色，不硬编码蓝色。

## 回复中的过程与来源

正文的运行标题、灰色编号文献、技能信息入口及跨端区别统一见[对话规范](CONVERSATION_UI_DESIGN.md)的“运行与思考”“引用与产物”。回复展开和右侧检查器展开是两份展示状态，不互相覆盖；检查器折叠不能改变 Run 终态或隐藏唯一授权入口。
