# 会话右侧检查面板

核对：2026-11-12，本地当前工作树。此页定义已接受的检查器交互；原型未同步的切页演示不覆盖本契约。源码与跨端边界见[客户端交互与配置](../../architecture/模块/13-客户端投影/CLIENT_INTERACTION_AND_CONFIGURATION.md)。

## 一级区域、原地展开

桌面只有一个右侧检查器。Mac 顶部三个图标分别切换任务、产物、上下文三个独立的一级区域，不能把它们实现成同一长列中的三个滚动定位点。切换区域不替换中央对话、内容标签或左侧列表；各区保留滚动、展开集合和未提交编辑。面板内不再提供页面选择下拉框、二级工具页或返回栈。Web 当前仍使用同一面板的原地展开布局，不能把 Mac 的完成状态写成 Web 已切换独立区域。

- 任务区包含概览、进度、目标；产物区包含审阅、产物；上下文区拆分为会话配置（会话沙盒、作用于主 Agent 后续回复的会话指令）、上下文预算（用量、只读要点摘要、独立 Wiki 运行笔记草稿、历史召回与会话资料）、执行、参与者，避免「上下文 > 上下文」重复层级和双指令文本框混淆。当前区域内可同时展开多个区段，其他区域的内容不混排进当前区域。
- 点击分组标题原地展开/收起；从顶栏定位工具时展开对应区段并滚动到它。面板有固定标题和明确关闭动作。
- Mac 知识点、Wiki、历史召回也在原地展开，取消内部互斥标签。关闭一项不覆盖另一项的编辑内容。
- 每个一级区域使用一个主要滚动表面，切换时保留其阅读与编辑状态；长代码、文档阅读器可有自身必要的滚动，但不让每个工具区都成为固定高度滚动窗。
- 预设提示词归入模型设置。Mac 在会话模型设置中选择模板，保存前属于编辑器草稿；iOS 在会话设置的模型区选择并即时提交。移动位置不改变模板或会话的持久所有者。
- 模型连接、账户、密钥和全局默认仍由模型中心管理；从会话设置访问它们须明确作用范围。

手机使用独立会话列表、原生面板/底部表单或 Web 抽屉，不缩小桌面三栏。iOS 资料详情在列表内展开；不要求 iOS/Android 已具有桌面全部检查器分组。

## 导航与信息去重

左侧承载全局功能，右侧承载当前会话。桌面「资源」一级列出数据中心、自动任务、模型、Skills / MCP 与系统访问，使自动任务与能力/资料处于同一发现层级；数据中心内部同时提供资料、长期记忆与自动任务视图。历史活动不再占据左侧主入口；提醒、任务与错误恢复沿用其原有业务入口。已有深链接继续有效；设置在每个左侧列表中只出现一次。

右侧概览不再重复下方分组的跳转按钮或产物列表。进度显示待办计划，目标显示目标控制、验收要求和工作记录，执行显示任务；同一任务不同时出现在进度和执行。iOS 目标控制只在目标面板出现。Mac 上下文中的知识编辑器默认收起，只有显式定位某项才自动展开它。

会话内的权限模式、资料覆盖和错误恢复继续保留。全局模型、Skill/MCP、系统访问与诊断由全局入口管理；右侧不再复制整套管理导航。上下文占用和缓存命中率直接可见，请求/尝试编号与片段诊断收进原地详细信息，不移除其可核查性。

## 内容与业务事实

| 语义 | 内容 | 边界 |
| --- | --- | --- |
| 概览 | 当前状态、需要用户处理的阻塞、来源 Host；Mac 提供工作目录选择 | 不给普通闲聊自动创建 Goal，不用工具次数或耗时估算完成百分比 |
| 进度/目标 | 待办计划与目标控制、requirements、工作记录分别展示 | 不复制同一目标与执行任务到多个区段 |
| 审阅/产物/资料 | 文件、附件、引用、差异和已有阅读入口 | 选中局部详情不切换中央标签；完整对象由显式打开动作进入阅读器 |
| 上下文 | 用量、知识点、Wiki、召回、会话级数据源 | 不混入模型账户或复制全局配置；未知用量不是零 |
| 执行/参与者 | 归属于原会话、Run、成员的执行记录与控制；Mac 的浏览器会话与连接 | 成员级配置必须指定成员，不拼接多个成员为一个虚假 Goal |
| 会话模型设置 | 当前模型覆盖、推理档位、模板、采样与输出限制 | 不增加与原生 effort 重复的“简洁/均衡/详细”选择器 |

`reported_done` 不是验收完成。未知状态显示可辨认文字，失败与空计划分开，重试就近可见。待授权、待回答和需要用户处理的失败在正文仍可发现，不得因面板折叠而隐藏唯一操作入口。

## 展示与生命周期

折叠集合、定位目标、滚动和动效属于客户端展示状态，不写入模型 prompt，不触发任务执行。消息、计划、Goal、配置与统计来自原有 Core/Application 投影，不建立检查器专属业务副本。

读取和编辑至少绑定 authority/Host、conversation、generation；成员内容再绑定 participant/Context/Run。切 owner 立即隔离旧内容，迟到结果不得写入新 owner。同一 owner 刷新失败保留最近成功内容及未提交草稿，并显示原位错误。

Web 首次展开相关区段时才挂载对应进度观察组件；已经访问的区段收起后保留组件与草稿。不能将“折叠”文档化为所有平台都已停止轮询。Mac 的读取任务遵循实际视图挂载生命周期，具体间隔不由本页另设一套常量。面板关闭、窗口隐藏和 Run 停止观察不是业务取消。

正文不继承检查器开合产生的整树布局动画，不重挂载消息列表，不重播历史流式内容。开合动画简短、可中断；减少动态效果时关闭位移与装饰动画。主题边界、焦点和悬停使用语义色，不硬编码蓝色。

## 回复中的过程与来源

正文的运行标题、灰色编号文献、技能信息入口及跨端区别统一见[对话规范](CONVERSATION_UI_DESIGN.md)的“运行与思考”“引用与产物”。回复展开和右侧检查器展开是两份展示状态，不互相覆盖；检查器折叠不能改变 Run 终态或隐藏唯一授权入口。
