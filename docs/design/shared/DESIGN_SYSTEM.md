# Nola 视觉系统与组件规范

核对：2026-11-14。现行组件行为以本页、[对话设计](CONVERSATION_UI_DESIGN.md)和[检查器规范](CONVERSATION_INSPECTOR.md)为准。跨端颜色角色、字号阶梯、圆角与间距以机器可读真源 [shared/design-tokens/tokens.json](../../../shared/design-tokens/tokens.json) 为准，并由 `python3 scripts/check_design_tokens.py` 执行跨平台对齐与 WCAG AA 对比度门禁。原型[视觉规范](../prototype/docs/DESIGN-SPEC.md)保留总体视觉方向，避免从历史截图复制另一套常量。

## 适用范围与层级

这份规范记录接受的视觉方向及跨端映射；原型是静态 HTML/CSS/JavaScript 演示，不等于生产客户端已实现。源码功能依据和已测范围见[能力覆盖矩阵](../prototype/FEATURE-COVERAGE.csv)，原型检查与生产验收边界见[验证说明](../prototype/docs/VALIDATION.md)。

日期化色值、平台截图与原型版本不另立一套现行色板。各端通过语义主题资源定义实际表面、强调、边界与状态色；历史记录不得覆盖当前交互和可访问性要求。执行、审批和数据语义仍分别由[对话与工具设计](CONVERSATION_UI_DESIGN.md)、[权限恢复契约](权限配置与恢复交互_20261016.md)及 Core 契约约束。

## 共同视觉方向

- 手机默认呈现会话列表；活动承接待回应与执行事项，资料和设置独立。普通闲聊不自动变成任务。
- 桌面面向持续对话和生产力：唯一 48px 全局顶栏、浏览器式内容标签、独立侧栏及右侧工作检查器。侧栏筛选与右侧工具切换不替换中央内容。
- 不在画布放置额外大标题或第二层全局导航；使用内容自身层级、安静留白和中性色背景组织页面。
- 主对话流仅由主 Agent（`Nola`）面向用户发言，正文排布在中性底色上；专家协作通过回复内的可展开过程摘要与只读子会话（「查看专家会话」）呈现，不渲染独立专家聊天气泡，也不设置 8 色专家气泡预设。复制、重试及编辑重发位于消息气泡外。
- 图标和颜色不能单独承载状态；焦点、键盘、触控目标、系统字号和减少动态效果必须可用。

## 平台适配

桌面客户端（macOS/Web）采用同一信息层级与单顶栏/标签/侧栏关系，遵循原生窗口与输入方式。移动客户端（iOS/Android/Web 窄屏）遵循会话列表优先、全屏聊天和原生触控语义，不将桌面三栏缩小后照搬，也不将手机列表直接放大成桌面首页。共用语义不要求像素布局相同。

CLI 只呈现相同的内容、执行及权限事实，不模拟图形窗口或装饰布局。

## 组件和验收约束

消息身份、气泡外操作、工作工具、授权卡与编辑重发遵循现行对话与检查器契约；原型只证明它自身的演示行为。工具输出不是回答正文；待处理授权不得藏在普通折叠区域；客户端不可由提示词或外观推导授权。实际执行和权限仍服从当前服务契约。

原型自身的浏览器/DOM/合成像素检查仅说明原型范围。生产 UI 的真实窗口、键盘焦点、滚动锚定、动态状态、授权与恢复必须按[视觉验收契约](VISUAL_ACCEPTANCE_CONTRACT.md)单独验证。未实际检查的页面、平台或状态必须标为未验证。

## 统一表面与语义色板（Warm Ink & Warm Paper）

所有图形客户端与交互原型共享同一套暖纸浅色（Warm Paper）与暖墨深色（Warm Ink）核心表面定义，消除纯黑 `#000000` 或冷蓝灰 `#0F1115` / `#141517` 的跨端漂移；机器可读定义位于 [tokens.json](../../../shared/design-tokens/tokens.json)：

| 语义角色 | Token 键 | 浅色（Light） | 深色（Dark） | 说明 |
| --- | --- | --- | --- | --- |
| 画布主底 | `canvas` | `#F7F6F3` | `#131312` | 页面与会话阅读主画布、Windows 启动宿主底色 |
| 卡片与输入表面 | `surface` | `#FFFFFF` | `#1B1B19` | 面板、卡片、输入框、弹层主体 |
| 次级与侧栏表面 | `surfaceSubtle` | `#F1F0EC` | `#232320` | 侧栏、分段底槽、列表填充与弱化容器 |
| 抬升表面 | `surfaceElevated` | `#FFFFFF` | `#232320` | 浮层与抬升容器语义色 |
| 主要正文 | `ink` | `#181817` | `#F2F0EB` | 主标题、正文与主图标（对比度 >= 13.8:1） |
| 次级文字 | `inkSecondary` | `#5C5B57` | `#A3A09A` | 摘要、辅助说明与次级标签（对比度 >= 5.9:1） |
| 弱化元信息 | `inkMuted` | `#66655F` | `#96938D` | 时间戳与次要元数据（对比度 >= 5.1:1） |
| 细分隔线 | `border` | `#E5E3DD` | `#2E2D2A` | 暖色单像素发丝分隔线与面板描边 |
| 控件描边 | `outline` | `#7A7872` | `#827F79` | 可交互输入框与次按钮边界（非文本对比度 >= 3.0:1） |
| 主动作与焦点 | `accent` / `onAccent` | `#181817` / `#FFFFFF` | `#F2F0EB` / `#131312` | 暖墨主按钮与语义焦点，不硬编码品牌蓝 |
| 状态语义色 | `success` / `warning` / `danger` / `info` | `#237047` / `#865400` / `#AD3D34` / `#1F5F8B` | `#82C99B` / `#E9BD66` / `#EFAAA2` / `#8AB8E6` | 在浅/深表面均满足 WCAG AA `>= 4.5:1` 文本对比度 |

## 当前组件规则与实现映射

| 组件 | 当前约束 | 实现入口 |
| --- | --- | --- |
| 边框与焦点 | 使用主题语义色，不硬编码蓝色；焦点与选中态分开 | Apple `DesignTokens`/`MacDesignColor`，Android `NolaSurface`，Web `theme.css` |
| 桌面按钮 | 浅/深色均有悬停和按压反馈，尺寸不变；图标动作有可访问名称 | `MacPageChrome.swift` 与 `NolaControlHover/Pressed` 资源 |
| 回答复制 | 无常驻边框/背景；移动端不依赖悬停才发现 | `MacMessageView`、`MessageCopyAction`、`ChatMessageActions.svelte` |
| 手机输入 | 满宽文本 + 底部紧凑操作；不常驻堆叠多排状态/参数 | `ChatComposer`、`ChatScreen`、`Chat.svelte` |
| 推理选择 | 当前模型声明的完整档位，紧凑菜单与选中标记；不并列三档控件 | 各端 `ReasoningEffortMenu`/`ChatReasoningMenu`、`MacComposerView` |
| 检查器 | 独立展开、单一主滚动区，不设置页面选择器 | `MacChatInspectorView`、`Chat.svelte` |
| 动效 | 可中断、少装饰，历史消息不重播；支持减少动态效果 | Apple 原生动画、Android 预测返回、Web motion token |

表中名称用于定位当前源码，不意味着所有平台使用相同控件或相同像素尺寸。触控目标、长文本、动态字号、320/390 窄屏及深浅色须分别检查。
