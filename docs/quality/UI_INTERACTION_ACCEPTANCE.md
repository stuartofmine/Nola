# 客户端交互验收

Nola 的主要任务是让用户可靠地提交意图、理解执行过程并处理需要回应的事项。平台实现可采用各自的原生控件，输入、执行事实、权限与恢复语义须一致。

## 判定规则

- 编译、协议测试、渲染测试、真实模型调用、客户端实际操作分别记录，不能相互替代。
- 每条流程同时检查正常路径、失败路径、恢复路径及用户输入是否保留。
- 模型生成内容需要独立检查语义。能解析、有尺寸或生成了文件，都不能证明内容正确。
- 每个平台单独记录结果；Web 结果不证明 Windows 系统集成，Apple 共享源码不证明 iOS/Mac 界面相同。
- 新增回归应证明能够拦住原问题；适合时临时还原错误行为，确认断言失败，再恢复修复重测。
- 原始记录使用独立数据库和测试目录。真实账户授权、用户消息和个人设置不得为方便验收而删除或重写。

## 必须覆盖的流程

| 场景 | 操作与独立预期 |
| --- | --- |
| 首次使用与模型选择 | 无模型时给出可执行入口；返回后草稿保留；取消授权不显示成功 |
| 普通输入 | 中文输入法确认不误发送；连续点击只提交一次；失败保留文本和附件；未知回执查询原请求 |
| 编辑重发 | 精确引用原消息和配置；同一会话回溯至编辑点并替换后续输出；失败仍可编辑；旧会话回执不写入新会话 |
| 专家模板 | 七类角色可预览提示词、工具包和关联 Skill；应用前确认替换已有选择；保存、重开和名称/描述编辑保留原配置；模板不是安装或授权 |
| 专家推理 | 仅显示实际模型声明的 effort；继承应用默认模型并及时更新；自动不写成 none；显式档位进入冻结请求，不受原三档覆盖；旧 Host 不伪装支持 |
| @ 引入 | 完整目录、重名可辨、按 ID 与观察到的版本加入；空白草稿不因打开菜单创建会话；加入失败保留 @；会话或草稿切换后旧回调无副作用 |
| 专家更新 | 旧成员维持加入时快照；显式确认重新加入才更新，取消不写；新上下文与旧历史分开，版本冲突和未知回执不能盲目重试；独立模型专家不要求另选主模型 |
| Goal | 创建、继续、暂停、恢复、完成各有明确状态；进度和消耗来自已提交事实；待确认操作不能由新文案绕过 |
| 流式回复 | 正文、推理、工具和图形顺序正确；断流可恢复；停止后无新增副作用；选择与滚动不被抢夺 |
| 原生表单 | 发布无需通用风险弹窗；填写、校验、提交、重复点击、过期内容、冷启动重查、明确拒绝和失败重试分别验证 |
| 表单内容状态 | 当前内容只显示一次，无内部 revision 标签；准备中和已移除显示状态；历史内容必须只读，不能冒用最新快照 |
| 图形 | 实际图形渲染；检查事实、分组、箭头与标签；拓扑不冒充地理位置；解析失败能查看原文；生成中避免反复重建图形 |
| 权限 | 提示具体操作、资源与后果；同意一次不授权后续操作；拒绝后给出操作入口；未知回执不改成拒绝或成功 |
| 宿主机 | 配对、证书拒绝、离线、重连、取消、前后台与冷启；切换宿主机不带入旧权限和提交 |
| MCP / Skill | 安装、启停、缺少凭据、连接失败、调用失败、撤销与恢复；能力选择依赖工具合同，不依赖提示词关键词 |
| 设置与更新 | 每个入口可到达并能返回；切换主题、语言后即时一致；保存失败保留编辑；升级错误不删除用户数据 |

## 界面减负与点击范围

- 普通导航行以名称为主；移除复述标题的说明和重复行尾箭头。展开/收起、返回和外部跳转保留有实际含义的方向提示。
- 可点击行的文字、图标与留白属于同一个点击区域；独立开关保持独立操作，不嵌套按钮。移动端主要行至少 44 pt（Android 48 dp），Mac 常规操作行至少 36 pt。
- 控件保留横向内边距及悬停、按下、键盘焦点反馈；不能只扩大背景而仍要求点击小图标。
- 权限后果、当前状态、错误恢复及作用范围存在歧义时保留必要说明；不以精简为由删掉用户决策依据。

## 界面状态组合

以上流程检查明暗主题、最窄支持尺寸、200% 文字、长内容、中文与长译文、键盘导航、读屏标签和减少动态效果。按钮保留舒适的点击区域与内边距，状态不能只靠颜色；恢复入口不能藏在只有技术人员理解的错误文本中。

参考：`apple-design` 的 `accessibility.md › Vision` 要求 “Support larger text sizes”；`layout.md › Adaptability` 要求 “Be prepared for text-size changes”。Android 与 Web 应用对应的可读性和可恢复性原则，保留自身平台习惯。

具体通过范围及未覆盖项见 [当前验收范围](VALIDATION_SCOPE.md)。不能通过静态原型、页面数量或组件测试总数宣布全平台业务验收完成。

Web 图形使用仓库内已有 Mermaid 库，在无同源权限的 iframe 中渲染，并限制网络访问；不加载外部 CDN。[Mermaid 官方说明](https://mermaid.js.org/config/usage.html#securitylevel)中的 `strict` 配置是图形内容处理的一层，不能替代客户端自己的隔离和失败恢复。


## 图形流式展示与原生内容选择

Mermaid 的未闭合代码围栏显示稳定的准备占位，不逐 token 解析或切换错误/源码/图形。围栏闭合即可展示，无需等待整条回复结束；之后追加正文不重建已完成图形。尺寸更新只接纳当前渲染的非零结果，卸载或被后续更新取代的回调不得改写新尺寸。错误只在完整输入上呈现。

Intelligence UI 的模型合同同时示范表单与只读卡片，说明卡片、分页比较、可调选项和多步交互的适用性。由模型根据工具 schema 与展示收益选择，不要求用户说出工具名，不以关键词强制路由，也不将每条普通回复包装成冗余卡片。真实模型验收使用自然语言的可填写内容需求，并检查生成、填写、提交及精确历史恢复；带工具名的强制提示不能证明模型会自主选择该能力。

## Mac 处理中动效

处理中的主提示、当前执行摘要和运行状态使用柔和单色亮带流过文字；底层文字始终可读，字形、基线和行高保持固定。亮带完全离开文字后循环，避免接缝闪烁；不将动画传递给整条消息或列表布局。完成、失败、等待授权和等待输入的状态不播放流光。开启减少动态效果、窗口场景不活跃或视图不可见时停止连续刷新。

验收同时比较明暗主题的动画关键帧，以及实际 TimelineView 在运行、停用、后台和减少动态效果下的连续采样；不能仅凭布尔条件测试认定动画通过。

## 过程记录与当前活动

思考过程和执行过程是中性的记录容器，不显示“成功”“失败”或“已完成”等结果徽标；工具结果仅属于对应的调用，不能由一次失败推断整轮失败。真实回复中断、需要授权和需要用户回答的入口独立保留，不得藏进历史。

实时只在折叠入口预览当前活动，历史步骤默认收起。新思考、新工具和失败步骤均不自动展开整组记录；用户展开或收起的选择在流式更新、重试和分组变化后继续有效。完成后入口恢复中性名称，失败及重试的原始顺序和细节仍可展开检查。四端展示使用同一规则，不改写 Core 状态或持久化数据。

回归至少覆盖：一次工具失败后重试成功、工具失败后继续思考、并行调用中较新的调用先结束、真实回复失败、等待授权、长记录追加和手动展开/收起后的继续更新。

## 左右侧栏职责与去重

- 左侧提供会话和全局资源；数据中心统一承载记忆、自动任务等子功能，不在资源列表再次平铺。已有深链接与搜索直达能力保留，子页选中时父入口有正确选中态。
- 右侧概览只展示当前状态和工作区；计划、目标、执行、产物各占唯一位置，不复制跳转目录或同一列表。浏览器属于执行，上下文保留会话记忆/检索、用量、知识及数据源。全局工具管理不再在右侧复制。
- 设置在每个左侧列表只出现一次。置顶分组不在每条记录上再重复图钉；无置顶记录时不增加一层“最近”标题。会话标题与预览相同时不重复显示预览。
- 明暗主题与宽窄尺寸都渲染全部检查器区段；真实点击验证区段顺序、唯一内容归属、资源入口与设置操作。截图和原生点击回归均使用隔离存储；与用户正在运行的真实窗口验收分开记录。

## 草稿、附件与异步返回的验收清单

以下项目分别在支持对应能力的 Mac、iOS、Android、Web 客户端执行。某平台没有该入口时记录“不适用”及原因；不得拿另一平台的结果代替。使用隔离数据、测试文件和受控服务；普通配置保存不触发模型推理、MCP 调用或真实账户配对。

| 场景 | 具体步骤 | 通过判定 |
| --- | --- | --- |
| 模型配置退出 | 输入地址、模型和凭据，切换服务、本地、宿主机来源；关闭后选择继续编辑，再关闭并明确放弃；重新进入 | 来源切换保留草稿；存在改动时退出须确认；继续编辑保持原文；放弃后重新进入无残留；所有来源均有可操作的返回/关闭入口 |
| 模型参数原文 | 保存含缩进、首尾空格和连续换行的系统提示词；关闭重开；只修改另一参数再保存 | 提示词逐字符一致；未修改的参数不被重置；保存失败仍能编辑原稿 |
| 键盘与固定动作条 | 在参数文本框、数字框中输入，保持键盘展开点击保存，再收起键盘；使用窄屏和辅助功能大字号重复 | 保存按钮可见、可点击且不被键盘工具栏遮挡；收起键盘入口与保存处于同一受控布局；自定义主要动作触达高度至少 44pt，无负数或无限尺寸警告 |
| 退出确认的系统适配 | 从每一种模型来源关闭有改动的配置，在系统以弹窗或浮层显示确认时分别保留、放弃 | 两种选择始终有显式入口，不能假定 cancel 角色一定在 popover 中呈现；继续编辑保留原文，放弃只影响本次草稿 |
| 宿主机凭据范围 | 对已配对地址留空令牌并显式连接；分别改主机、协议、端口和路径后重试；另行输入替换令牌 | 只有原批准地址可复用已保存凭据；换地址不得读取或发送旧令牌；显式替换令牌不读取旧令牌；无凭据时显示补充入口 |
| 宿主机地址错误 | 输入带用户信息、查询串、片段、非法端口的地址，及不允许的公网 HTTP 地址 | 在网络请求前拒绝并保留输入；不保存为已配对；普通错误信息不含令牌 |
| 权限步骤返回 | 点击申请后尝试跳过、滑到下一步及关闭；延迟返回允许/拒绝；再打开流程 | 请求只归属原步骤；旧页面回调不推进新步骤或展示过期错误；拒绝有恢复入口；取消不显示成功；减少动态效果时无强制过渡 |
| 附件会话归属 | 在会话 A 打开文件选择器，切换或删除 A，再让成功、失败、取消回调返回；同时在 B 开始另一导入 | 成功内容及失败提示只归属原草稿；不覆盖 B 的输入或导入；删除的会话不被重建；重复回调仅处理一次；取消结束等待状态 |
| 图片与链接粘贴 | 分别粘贴本地文件、截图位图、普通 HTTPS 链接；模拟图片临时写入失败 | 本地文件和位图进入附件；普通链接留在文本中；写入失败可见且保留已有草稿；不留下不可见的“正在导入”状态 |
| 文件导入错误 | 分别选择有效 UTF-8、空文件、无效编码、超出限制的文件及混合批次；取消系统选择器 | 接受内容保持原文；超限或无效内容明确报告，不能静默截断；批次成功项保留；取消不弹失败；返回后能继续选择 |
| 长文阅读与复制 | 展开长回复，选择中段文本并继续流式追加；复制带代码缩进和连续换行的完整内容；模拟复制失败 | 不抢夺滚动和选择；复制保持原文；失败提供可选取原文的恢复界面；提示不覆盖操作控件 |
| Skill / MCP 编辑 | 新建并保存；重开修改后取消，分别选择保留、放弃；模拟存储冲突或失败，再关闭重开 | 保存回执对应持久化内容；失败保留草稿和错误；放弃不修改原记录；取消无副作用；MCP 地址不被自动纠正；配置保存不冒充服务连接成功 |
| 数据源测试返回 | 输入地址并开始验证；尝试改地址、格式及类型；取消后立即验证另一地址；延迟返回旧结果 | 编辑受控或旧请求被退休；预览、验证合同及成功状态均属于当前地址；旧结果不启用新地址保存；取消后能重试 |
| 数据源删除回执 | 从旧快照发起删除，在另一客户端先更新同一源；分别测试冲突、无权限、存储不可用和成功 | 失败保留列表及持久化记录并显示错误；成功回执后才移除并通知；重复删除有明确结果；全量清理有任一删除失败时不得报告全部成功 |

原生弹窗、文件提供商、后台恢复与实际网络端点需要单独验证。单元测试可验证版本冲突、请求归属、大小限制和故障回执；不能据此认定系统文件选择器、iCloud 文件下载、真实授权弹窗、读屏或长文滚动流畅性通过。受限同步读取仍可能被文件提供商阻塞，大小上限也不等于后台导入或批量耗时已受控。真实模型、真实 MCP 服务调用及真机前后台验证须在各自范围单独记录。

## 专家真实执行验收

`scripts/test_real_expert_roles.py` 使用隔离 Host、数据库、项目与 loopback relay，复用已配置 Responses 连接在内存中的凭据，可能产生模型费用。当前验证主 Agent 经 `delegate_expert` 调度独立高档位专家、同一专家历史续接，以及专家缺少信息时由主 Agent 向用户澄清；检查真实 Task/Run、单一主会话用户消息和专家叶子工具面，不允许专家再次派生。`--collaboration-only` 为同一流程的兼容参数。旧专家互调或直接 Room 交付的结果不能当作本架构验收，也不能代替代码交付、Skill 调用或独立测试的证据。

真实项目操作仍使用产品权限链路。测试只能对自己临时仓库、已核对的实际 pending 工具输入提交一次性许可；未知操作或交付范围必须停止。使用 Git 检查待审批仓库时设置 `GIT_OPTIONAL_LOCKS=0`，避免只读状态检查刷新 index 或目录版本，使原批准资源失效；资源确实变化后必须重新核对并取得新许可。此脚本不证明所有角色的外部服务可用、所有模型支持全部档位，也不修改用户数据库或账户。
