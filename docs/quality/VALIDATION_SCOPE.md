# 当前验收范围

## 单一主 Agent 与专家 Task（2026-11-13）

当前入口由主 Agent 接收用户输入和类型化 `@` 选择，再按需调度叶子专家。专家使用独立模型、推理档位、角色、工具和持久子会话；不能继续派生专家或直接向用户提问。此前专家互调的测试不作为这条链路的完成证据。

隔离环境下的真实模型回归已完成四轮主会话、四个专家 Task 和 16 次上游请求，覆盖首次调度、同一专家历史续接、缺少信息返回主 Agent，以及用户澄清后重新调度。实际专家 schema 不含直接提问和递归调度工具；主会话保留四条原始用户输入。Core 专家边界 32 项、主会话提问 14 项通过，后者另有一项既有辅助用例忽略。

共用执行泵 48 项测试通过，覆盖正常提交 ACK、按 effect 隔离中止、空闲/流式请求取消及规范终态；这些是运行时与受控 Host 测试，不代替原生模型连接停止的实测。取消必须同时核对真实执行停止、精确 Cancel 确认和 Core 终态，不能用流结束或传输错误代替。

连续对话补测还发现两处重复工具调用 ID 的边界：移动端流式组件缺少 attempt 作用域，共用来源绑定及组件创建误用旧消息记录。修复保留上游调用 ID 和旧历史，以当前已接受的调用、Turn/Message 及实际 attempt 区分来源和组件。在途结果跨用户补充输入仍归原调用。最终引擎库 605 项、来源范围 8 项、主会话提问 14 项通过，提问套件另有一项既有忽略；包含真实数据库跨 Run、同 Run 新消息段、无流式增量及伪造来源拒绝的回归。

## 专家工具包精简（2026-11-12）

默认业务工具按角色收窄，删除通用协议的重复展示；审查默认只读，秘书不预装文件/Shell，画师仅发现实际配置的绘图能力。编写/审查改用已声明的 `code_search`、`git_diff` 等工具，移除不准确的默认工具名。Core 捕获的执行指引同步要求在专业范围按需补充，不加载无关工具包。原型与目录保持逐字段一致。

验证包括角色目录回归、Host 真实工具声明与审查只读契约、原型静态一致性。此轮是共享配置与指引调整，没有重新运行原生 UI、真实模型或打包各平台安装包；不能据此宣称宿主工具发现目录已被隔离。此前专家功能的完整验收见下节。

## 专家角色、推理档位与 @ 引入（2026-11-12）

新增代码编写、代码审查、测试、私人秘书、画师、PPT 制作、论文写作七个起始角色，Core 提供同一版本化目录，包含提示词、工具包及关联 Skill。新建的四个代码/测试/绘画 Skill 是实际内置包；已有秘书、演示文稿及论文包继续复用。角色不自动安装、启用或授权工具，外部服务不可用时不能以模板替代真实产物。

专家独立保存 effort，选项来自实际模型声明，不再折回三档；自动继承不写成 `none`。未固定模型时跟随应用默认聊天模型，已有编辑器随默认变化更新。@ 使用目录 ID 与观察到的版本；空草稿观察不建房，已有成员维持加入时配置，明确确认重新加入才换新上下文。保存冲突及不确定回执保留草稿，跨会话/草稿的旧返回不能影响新页面。当前单主 Agent 架构仍要求主 Agent 有可用模型；专家的独立模型不能替代主会话的调度模型。

本次只增加可选 JSON 字段和命令，不重置协议、ABI、数据库格式或 epoch。原有省略新字段的生成意图保持原序列化；不支持新能力的旧 Host 显示指引，不伪装保存或执行成功。设计、架构与业务原型同步。

## 配置草稿、权限返回与异步页面审计（2026-11-12）

本轮按 iOS、macOS、Android/Web 三路审计，重点检查切换来源、退出编辑、延迟回调、离线重试及失败后的恢复。修复包括：宿主机旧凭据只在原批准地址显式连接时读取；模型草稿跨来源保留并确认放弃；登录关闭等待取消回执；附件返回绑定原会话；普通链接不误作附件；文本导入不静默截断、复制保留原文；数据源删除确认持久化成功后才移除列表。活动列表与详情按查询和会话/Run/助手消息校验归属，失败保留同一查询的成功快照，旧返回不能覆盖新页面。

实际截图与控件操作还发现并修复了：iOS 自适应确认浮层省略“继续编辑”、键盘工具栏覆盖参数保存条、Skill/MCP 自定义动作触达范围不足，Mac 窄窗 Host 表单重复可见标签，以及深色活动搜索占位文字对比不足。参数页收起键盘与保存使用同一有界动作条，辅助功能字号改用纵向布局；不再用无限宽按钮参与 `ViewThatFits` 测量。

Web 补齐局域网环境缺少 `randomUUID` 时的 Skill/MCP 新建、缺少 Web Locks 的明确连接指引、移动抽屉遮罩关闭与焦点返回，并禁用初始化失败时无法打开的上下文入口。Android 修复恢复标签后又退回根页的问题，补充永久拒绝权限后的系统设置指引。随机标识仍使用系统安全随机源；并发锁、权限判定及凭据边界没有因兼容浏览器而放宽。

## 同会话编辑重发（2026-11-12）
