# 当前验收范围

核对：2026-11-10。远端权限/长任务实现来自 `3c1feca`，全业务原型来自 `72f998f`；目录迁移不重新运行真实模型，也不更改协议、ABI 或数据库。这里保留公开的范围说明，不分发任务流水、日志或生产数据。

| 层次 | 实际覆盖 | 限制 |
| --- | --- | --- |
| Web → 真实 Host / 模型 | 200 次依赖节点读取、10 检查点、报告与独立预期核对；约 30 分钟，两次实际压缩 | 不等于单 shell 循环；只属于所测模型路线 |
| Web 断线与取消 | 页面离开后源 Run 继续；冷标签仍是同一 Run；另一作业取消后物理写入停止，后续追问成功 | UI 结束、SSE EOF 与进程结束不能混同 |
| Host 冷启动追问 | 相同独立 Store、新进程/浏览器找回已保存上下文中的原标记；旧 Run 不重放 | 不表示任意未知写入能自动恢复 |
| Android → Host | 实际 MainActivity、一次具体审批、两分钟作业；退出并强制停止客户端后源 Host 继续，冷启恢复同一 Run、120 次连续进度与正确结果 | 120 个物理进度点不是 120 次模型工具调用；模拟器及 adb reverse 不证明双设备 Wi-Fi |
| Android 收尾 | 另一次 90 秒作业核对具体命令/目录与完成后停止按钮恢复发送 | 不扩大为所有系统权限、语言和字号 |
| 权限回归 | 权限/SSE/切换会话 16 项、缺详情界面 1 项、独立结果 oracle 7 项通过 | 配对、设备 OS 权限及具体工具授权仍有不同边界 |
| 全业务原型 | 68 场景、220 状态、2,082 平台/主题状态、429 条交互边，288 张主图；60 个尺寸组合和 12 张平台长任务图 | 合成设计回放，不是 2,082 个真实业务 E2E |
| 既有完整原型 | 10 组流程、134 张截图；与新原型均无浏览器异常及外部请求 | 不模拟真实登录、MCP、系统授权或安装 |

Web 生成路线共 236 次请求，234 次成功，两次真实上游传输错误恢复后完成；没有伪造生成响应。测试中继本地拒绝非指定路线，不计为成功生成或上游错误。Host 冷启动追问另有一次成功请求；Android 两分钟轮次五次真实请求全部成功，90 秒轮次另计。

## 复现与判定

- [Web 长任务脚本](../../scripts/test_real_remote_host_long_tasks.py)：`--nodes 200` 使用当前选定真实模型与独立 Store；`--smoke` 只有四个节点，不计为数百步。`--resume-evidence` 在原验收通过后重启同一夹具，另存追问回执。
- [Android 长任务脚本](../../scripts/test_real_android_remote_long_task.py)：要求显式专用模拟器、可丢弃次要用户、明确 AVD 与作业时长；禁止使用主用户或生产数据库。
- [原型入口与检查](../design/prototype/README.md)：不调用模型或真实 Host；场景、路由及状态图检查和原生执行证据分开。

真实模型验收会产生费用。完成须同时核对 canonical Run/result、已提交工具记录、独立文件结果、一次物理启动与正确助手消息；取消须核对实际副作用停止。原始记录仅在本地，不能为了目录迁移重新生成或改写通过结论。
